# 人猫搭档 AIGC 项目 V1.7 NEW 入口交互优化实施方案

> 日期：2026-07-03  
> 范围：`入口/入口_NEW.html`  
> 前提：旧入口 `入口_开始这里.html` 保留，不做替换。

## 1. 目标

围绕 NEW 入口补齐实际使用体验：

1. 表单内容一屏放不下时，左侧表单区域可以滚动，不再遮挡 `分镜视角`、`分镜布局` 等底部字段。
2. 页面可基于当前最小入参 JSON 直接生成完整 Prompt，并展示在 `完整 Prompt` 标签页。
3. 浏览器本地模板能力继续保留。
4. 在页面醒目位置增加简单操作指南，降低使用成本。

## 2. 实施方案

### 2.1 表单滚动与底部遮挡修复

调整 NEW 入口布局：

- `form-panel` 保持独立滚动。
- 移除底部按钮栏的负 `bottom` 和负 `margin`。
- 底部按钮栏改为正常 sticky 底栏。
- 当页面高度不足时，表单内容通过滚动查看，不遮挡最后一行字段。

预期结果：

```text
V1.7 锁定与分镜
服装风格锁定 / 服装参考来源 / 当前图内分镜
分镜视角 / 分镜布局
底部按钮栏
```

上述内容在小屏或内容较多时可通过滚动完整访问。

### 2.2 当前 JSON 生成完整 Prompt

保留 `最小入参 JSON` 和 `完整 Prompt` 两个标签页：

- `生成最小入参 JSON`：刷新 JSON 与校验状态。
- `生成完整 Prompt`：基于当前 JSON 重新生成 Prompt 预览，并自动切到 `完整 Prompt` 标签页。
- `复制`：复制当前激活标签页内容。

说明：

```text
前端完整 Prompt 是预览版。
最终可追踪流水线产物仍以 tools/generate_prompt.py --input 输出为准。
```

### 2.3 本地模板能力保留

继续使用浏览器 `localStorage`：

- 内置外卖跑单模板。
- 内置居家治愈模板。
- 保存自定义模板。
- 删除自定义模板。
- 恢复内置模板。

模板只保存配置字段，不写入项目文件。

### 2.4 简单操作指南

在表单顶部增加醒目操作指南：

```text
1. 先选常用模板
2. 填写故事情节和补充说明
3. 生成 JSON 或完整 Prompt
4. 复制 JSON 跑脚本，或复制 Prompt 做人工确认
```

## 3. 验收标准

### P0 必验

| 编号 | 验收项 | 通过标准 |
|---:|---|---|
| P0-01 | 底部字段可见 | `分镜视角`、`分镜布局` 不被按钮栏遮挡 |
| P0-02 | 表单可滚动 | 内容超过一屏时左侧表单能滚动查看 |
| P0-03 | JSON 可用 | 默认外卖模板生成的 JSON 可被 Python V1.7 脚本接受 |
| P0-04 | Prompt 可生成 | 点击 `生成完整 Prompt` 后切到 `完整 Prompt` 标签并刷新内容 |
| P0-05 | 复制可用 | JSON / Prompt 两个标签页均支持复制当前内容 |
| P0-06 | 模板保留 | 内置模板和自定义模板功能仍可用 |

### P1 推荐

| 编号 | 验收项 | 通过标准 |
|---:|---|---|
| P1-01 | 居家模板 | 切换居家模板后 Prompt 预览使用居家分镜 |
| P1-02 | 张数变化 | 修改 3 / 6 / 8 / 12 张后，Prompt 预览张数同步变化 |
| P1-03 | 小屏适配 | 窄屏下表单和指南纵向排列，不横向溢出 |

## 4. 风险控制

| 风险 | 控制 |
|---|---|
| 前端 Prompt 与 Python 最终 Prompt 不完全一致 | 页面标注为前端预览版，最终产物以脚本输出为准 |
| localStorage 模板丢失 | 模板只作为便捷能力，核心仍是复制 JSON |
| 页面过长 | 左侧表单独立滚动，底部按钮栏不再遮挡字段 |

## 5. 结论

本次优化不改变 V1.7 生成流水线核心逻辑，只增强 NEW 入口的可用性。NEW 入口可以继续作为新版视觉入口草稿推进；正式替换旧入口前，仍需用真实浏览器和实际图片生成流程做 M5 验收。
