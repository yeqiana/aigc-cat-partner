# 人猫搭档 AIGC 项目修改意见整理

> 版本：V1.6  
> 整理时间：2026-07-02  
> 适用项目：`AIGC_人猫搭档_Project`  
> 目标：将用户多轮修改意见整理为可继续迭代、开发、验收的需求文档。

---

## 1. 背景说明

当前项目目标不是简单生成几张好看的图片，而是要形成一套可长期复用的 **人猫搭档 IP 内容生产流程**。

核心角色为：

- 同一个年轻女生
- 同一只白色银渐层猫
- 同一套真实生活摄影 / 拍立得质感
- 可稳定扩展到送外卖、居家、互动、连续剧情等多种内容场景

本轮修改意见主要集中在：

1. 跨会话身份一致性
2. 抖音竖屏大图支持
3. 气泡与文字开关
4. 自动文案生成
5. 多张图片生成
6. 连续故事能力
7. 观众互动能力
8. 顺序生成机制
9. 气泡文字内容落地
10. 组图服装风格一致性
11. 当前图内可选分镜视角
12. 生成前显式拆分剧情分镜
13. 第一张锚点图强制复用
14. 关键剧情视觉证据
15. 生成结果返工验收机制

## 3. 修改意见一：跨会话身份一致性

### 3.1 问题描述

在当前会话中，确实可以生成非常接近、甚至几乎一样的人物和猫咪。

但是切换到新会话后，生成出来的女生和猫咪样貌会发生变化，包括：

- 女生脸型变化
- 眼镜变化或消失
- 发型变化
- 猫咪品种变化
- 猫咪眼睛、脸型、毛色不稳定
- 整体风格偏离原来的拍立得生活摄影风

### 3.2 修改要求

不能只依赖文字 Prompt，需要建立 **跨会话身份锁定机制**。

每次新会话都必须支持上传以下参考素材：

```text
1. 人物原始参考图
2. 猫咪正面参考图
3. 猫咪近景参考图
4. 当前场景对应的母版图，可选但推荐
```

### 3.3 实现目标

新会话中也要尽量保持：

```text
同一个女生
同一只白色银渐层猫
同一套拍立得生活摄影风格
同一套服装 / 道具 / 场景风格
```

### 3.4 验收标准

| 验收项 | 通过标准 |
|---|---|
| 人脸一致 | 新会话生成后仍能看出是同一个女生 |
| 猫脸一致 | 新会话生成后仍是同一只白色银渐层猫 |
| 眼镜稳定 | 圆框眼镜不消失、不大幅变形 |
| 发型稳定 | 深色长发和刘海保持一致 |
| 猫品种稳定 | 不变成长毛猫、橘猫、布偶猫等其他品种 |
| 风格稳定 | 仍保持真实生活摄影和拍立得质感 |

## 4. 修改意见二：支持抖音竖屏单张大图

### 4.1 问题描述

原项目更偏向 4:3 图片或普通场景图，但后续内容需要适配抖音竖屏图文和视频封面。

### 4.2 修改要求

Prompt 生成入口需要支持以下配置：

```text
输出模式：单张大图 / 多镜头拼图
画面比例：4:3 / 9:16
平台用途：通用 / 抖音竖屏
```

### 4.3 抖音竖屏生成要求

当选择抖音竖屏时，Prompt 必须自动加入以下约束：

```text
只生成一张完整大图
不要拼图
不要多宫格
不要分镜框
比例为 9:16
主体居中偏上
顶部预留标题区
底部预留字幕/按钮区
人和猫都必须完整清晰可见
```

### 4.4 验收标准

| 验收项 | 通过标准 |
|---|---|
| 比例正确 | 输出为 9:16 竖屏 |
| 不是拼图 | 不出现九宫格、多宫格、漫画框 |
| 主体完整 | 人物和猫都完整清晰可见 |
| 平台适配 | 顶部和底部有安全留白区 |
| 可发布 | 可直接作为抖音图文或视频封面使用 |

## 5. 修改意见三：支持气泡和文字开关

### 5.1 问题描述

有些图片需要对话气泡、标题或旁白，有些图片不需要。

原来的 Prompt 不够灵活，无法通过少量入参控制是否生成气泡和文字。

### 5.2 修改要求

入口中需要支持以下配置项：

```text
气泡模式：
- 无
- 人物气泡
- 猫咪气泡
- 双气泡
- 旁白标题

文字模式：
- 无文字
- 空白气泡后期加字
- 直接生成文字

文字位置：
- 自动
- 顶部标题区
- 人物旁边
- 猫咪旁边
- 底部字幕区
```

### 5.3 推荐默认方案

由于图片模型直接生成中文容易乱码，默认推荐：

```text
气泡模式：双气泡 / 猫咪气泡 / 旁白标题
文字模式：空白气泡后期加字
```

即：

1. 先生成空白气泡图
2. 再用剪映、PS、Canva、小红书编辑器等工具后期加字

### 5.4 验收标准

| 验收项 | 通过标准 |
|---|---|
| 气泡可关闭 | 选择“无”时不出现气泡 |
| 空白气泡可用 | 气泡内干净留白，适合后期加字 |
| 气泡不挡脸 | 不遮挡女生脸、猫脸、眼镜和关键动作 |
| 文字不乱码 | 若选择直接生成文字，文字必须简短清楚 |
| 位置合理 | 文字或气泡符合所选位置 |

## 6. 修改意见四：文字支持自动根据情节生成

### 6.1 问题描述

原来虽然可以填写标题、人物气泡、猫咪气泡，但都需要手动输入，自动化程度不够。

### 6.2 修改要求

新增文案生成模式：

```text
文案生成模式：
- 手动填写
- 自动根据情节生成
```

### 6.3 自动生成内容

系统需要根据以下信息自动生成文案：

- 场景
- 动作
- 氛围
- 是否连续剧情
- 当前是第几张
- 观众互动模式

自动生成内容包括：

```text
标题 / 旁白
女生气泡文案
猫咪气泡文案
```

### 6.4 示例

#### 爬楼疲惫场景

```text
标题：最后三层
女生：快到了
猫咪：累鼠啦
```

#### 取外卖场景

```text
标题：取餐完成
女生：马上送到
猫咪：袋子好香
```

#### 收工回家场景

```text
标题：今日收工
女生：辛苦啦
猫咪：加餐吗
```

### 6.5 验收标准

| 验收项 | 通过标准 |
|---|---|
| 自动生成 | 不手动填写也能生成标题和气泡文案 |
| 符合场景 | 文案与当前画面情节一致 |
| 足够短 | 每句建议 4-12 字 |
| 可后期加字 | 文案可直接用于剪映/PS/Canva |
| 有人猫差异 | 女生文案和猫咪文案有角色区分 |

## 7. 修改意见五：抖音大图支持选择生成几张

### 7.1 问题描述

抖音图文内容通常不是一张图，而是一组竖屏大图。

原工具需要支持选择生成数量。

### 7.2 修改要求

新增生成张数配置：

```text
生成张数：1 / 2 / 3 / 4 / 5 / 6 / 8 / 12
```

### 7.3 关键要求

当比例为 9:16 且生成多张时：

```text
每张都是单独的大图
每张都可以单独发布
不要合成一张拼图
不要生成漫画九宫格
不要多宫格排版
```

### 7.4 验收标准

| 验收项 | 通过标准 |
|---|---|
| 张数可选 | 可选择 1-12 张 |
| 独立输出 | 每张都是独立大图 |
| 不合并 | 不生成拼图、多宫格、分镜框 |
| 可排序 | 生成结果有第 1 张、第 2 张等顺序 |
| 可发布 | 每张都能作为抖音图文单页使用 |

## 8. 修改意见六：支持是否为连续情节

### 8.1 问题描述

虽然已经可以生成多张大图，但这些图容易变成：

```text
同一个人物和猫咪
出现在不同场景里
但彼此没有剧情承接
```

这不是用户想要的。

用户真正需要的是：

```text
多张图片场景连贯
形成一个完整故事
每张图都承接上一张
每张图都推动剧情
```

### 8.2 修改要求

新增配置：

```text
连续情节：
- 否：同主题多张变体
- 是：前后承接的一组故事图
```

### 8.3 正确理解

用户不需要这种散图：

```text
第1张：送外卖
第2张：取外卖
第3张：骑车
第4张：爬楼
```

而是需要这种连续剧情：

```text
第1张：人猫准备出发
第2张：承接上一张，到店取餐
第3张：承接取餐，骑车送餐
第4张：承接骑车，到楼下抬头找楼层
第5张：承接楼下，开始爬楼
第6张：承接爬楼，送达到门口
第7张：承接送达，楼梯平台疲惫休息
第8张：收工回家
```

### 8.4 验收标准

| 验收项 | 通过标准 |
|---|---|
| 有剧情推进 | 每张图不是简单换背景 |
| 有前后承接 | 第 2 张能看出接着第 1 张发生 |
| 道具连续 | 外卖袋、电动车、外卖箱状态合理延续 |
| 情绪推进 | 轻松 → 专注 → 忙碌/疲惫 → 放松 |
| 有收束 | 最后一张有结尾感 |

## 9. 修改意见七：连续故事需要顺序生成机制

### 9.1 问题描述

如果一次性并行生成多张图，很容易变成散图。

即使 Prompt 中写了“连续故事”，模型也可能分别理解每张图，导致：

- 人物微变
- 猫咪微变
- 电动车不同
- 外卖箱不同
- 道具状态不连续
- 前后剧情看不出来

### 9.2 修改要求

连续故事模式下，必须明确生成流程：

```text
第1张：先生成故事锚点图
第2张：上传第1张锚点图 + 身份参考图，再生成
第3张：上传第1张锚点图 + 第2张成图，再生成
第4张及以后：上传第1张锚点图 + 上一张成图，再生成
```

### 9.3 推荐流程

```text
第1张 = 身份参考图 + 当前场景母版图
第2张 = 身份参考图 + 第1张锚点图 + 第2张场景母版图
第3张 = 身份参考图 + 第1张锚点图 + 第2张成图 + 第3张场景母版图
第4张 = 身份参考图 + 第1张锚点图 + 第3张成图 + 第4张场景母版图
```

### 9.4 目标

确保连续故事中：

```text
人物不变
猫咪不变
服装不变
电动车不变
外卖箱不变
道具状态连续
情绪有推进
故事有前后关系
```

## 11. 修改意见九：支持是否与观众互动

### 11.1 问题描述

抖音 / 小红书图文有时需要互动感，有时不需要。

比如：

- 问观众想点什么外卖
- 让观众选下一步
- 引导评论区留言
- 轻微点赞关注

### 11.2 修改要求

新增观众互动模式：

```text
观众互动模式：
- 不互动
- 看向观众
- 提问互动
- 评论引导
- 点赞关注
- 选择投票
```

### 11.3 示例

#### 选择投票

```text
标题：接着跑还是先休息？
女生：听你的
猫咪：我想休息
```

#### 评论引导

```text
标题：评论区说说你最爱吃啥
女生：我去取
猫咪：我来送
```

#### 提问互动

```text
标题：你会点哪一单？
女生：这单送哪儿
猫咪：你选吧
```

### 11.4 验收标准

| 验收项 | 通过标准 |
|---|---|
| 可关闭 | 选择“不互动”时不出现强互动感 |
| 可提问 | 选择“提问互动”时画面有轻微提问感 |
| 可评论引导 | 选择“评论引导”时文案适合评论区回复 |
| 不硬广 | 互动感自然，不像广告海报 |
| 不挡主体 | 互动文字或气泡不遮挡人物和猫 |

## 12. 最终产品目标

项目最终不是一个简单的图片生成提示词模板，而是要形成完整内容生产流程：

```text
少量入参
↓
自动生成稳定 Prompt
↓
支持跨会话身份锁定
↓
支持抖音竖屏大图
↓
支持气泡 / 文字 / 自动文案
↓
支持多张连续故事图
↓
支持观众互动
↓
形成稳定的人猫 IP 内容生产流程
```

```text
9. 支持同一组图服装风格锁定
10. 支持当前图内可选分镜，允许第一人称 / 第三人称视角组合
```

### 14.1 气泡文字内容落地

#### 问题描述

当前生成结果中可能已经出现气泡，但气泡内部没有实际文字内容，导致用户还需要重新构思标题、女生台词和猫咪台词。

需要明确区分两件事：

```text
气泡图形：画面里是否出现气泡
文字内容：标题、旁白、女生台词、猫咪台词是否已经生成
```

#### 修改要求

新增文字落地配置：

```text
文字落地模式：
- 仅生成文案清单
- 生成空白气泡 + 文案清单
- 生成空白气泡 + 后期叠字图层
- 直接在图中生成文字
```

推荐默认方案：

```text
生成空白气泡 + 后期叠字图层
```

原因是图片模型直接生成中文仍然容易乱码，稳定方案应是先生成干净气泡，再由系统把自动文案以文字图层方式叠加到图上。

#### 验收标准

| 验收项 | 通过标准 |
|---|---|
| 有文案内容 | 每张图都能输出标题、女生台词、猫咪台词 |
| 气泡不空 | 选择叠字或直接生成文字时，最终图里气泡不是空白 |
| 中文可读 | 文字清晰、不乱码、不缺字 |
| 可独立交付 | 即使不叠字，也必须输出可复制的文案清单 |
| 不遮挡主体 | 文字和气泡不遮挡人脸、猫脸、关键动作 |

### 14.2 组图服装风格一致性

#### 问题描述

同一组图片中，人物身份可能保持接近，但服装风格仍可能变化，例如上一张是外卖职业服，下一张变成日常 T 恤，导致组图不像同一次拍摄或同一段连续故事。

#### 修改要求

在身份锁定之外，新增服装风格锁定：

```text
服装风格锁定：
- 不锁定
- 弱锁定：同一风格，可有轻微细节变化
- 强锁定：同一套衣服、颜色、配饰、鞋包尽量一致

服装参考来源：
- 文字描述
- 人物参考图
- 第一张锚点图
- 当前故事模板默认服装
```

连续故事模式下默认使用：

```text
服装风格锁定：强锁定
服装参考来源：第一张锚点图 + 人物参考图
```

#### 验收标准

| 验收项 | 通过标准 |
|---|---|
| 服装类型一致 | 外卖服、居家服、T 恤等类型不跳变 |
| 颜色体系一致 | 主色、辅色、图案风格稳定 |
| 配饰一致 | 眼镜、帽子、包、外卖箱等关键元素不随机消失 |
| 符合剧情 | 服装变化必须有剧情原因，不能随机换装 |
| 组图统一 | 连续翻看时像同一组内容，而不是不同批次图片 |

### 14.3 当前图内可选分镜视角

#### 问题描述

部分画面适合在当前图里做分镜表达，例如同一张图中同时展示第一人称视角和第三人称视角，让动作、反应和环境关系更清楚。

但这与“抖音竖屏单张大图默认不要拼图 / 不要多宫格 / 不要分镜框”的规则存在冲突，因此必须做成显式开关。

#### 修改要求

新增当前图内分镜配置：

```text
当前图内分镜：
- 关闭：默认单画面大图
- 开启：当前图允许 2-3 个分镜

分镜视角：
- 第一人称
- 第三人称
- 第一人称 + 第三人称

分镜布局：
- 上下分镜
- 左右分镜
- 主画面 + 小视角窗口
```

默认规则：

```text
当输出模式为“单张大图”时，当前图内分镜默认关闭。
只有用户明确选择“当前图内分镜：开启”时，才允许出现分镜框、视角窗口或多视角组合。
```

#### 使用示例

```text
第 1 张：第三人称，女生和猫准备出发
第 2 张：第一人称 + 第三人称，上半部分是女生手拿外卖袋的第一人称视角，下半部分是人猫在取餐口的第三人称画面
第 3 张：第三人称，骑车路上
```

#### 验收标准

| 验收项 | 通过标准 |
|---|---|
| 默认不分镜 | 未开启分镜时仍输出单张完整大图 |
| 开启才分镜 | 只有明确开启时才出现分镜 |
| 视角明确 | 第一人称和第三人称画面能区分 |
| 不乱排版 | 分镜数量控制在 2-3 个，不生成九宫格 |
| 不破坏主线 | 分镜服务当前剧情，不变成无关拼贴 |

### 15.1 本轮生成结果问题归纳

基于 6 张外卖场景生成图的评审，当前结果主要问题为：

| 问题 | 具体表现 | 影响 |

| 动作推进不足 | 多张图都是站立、看手机、看猫，单张图没有清晰动作目标 | 叙事节奏弱 |

### 15.2 生成前必须输出逐张分镜表

连续故事模式下，不允许只依赖 `scene`、`story_template`、`image_count` 等字段让模型自动猜剧情。

生成图片前，系统必须先生成分镜表：

```text
第几张
本张剧情动作
承接上一张的内容
画面必须出现的视觉证据
人物情绪
猫咪状态
镜头视角
气泡和文字内容
是否允许当前图内分镜
```

#### 6 张外卖新手跑单推荐分镜

| 张数 | 剧情动作 | 必须出现的视觉证据 | 情绪 | 镜头建议 | 分镜建议 |
|---:|---|---|---|---|---|
| 1 | 接到第一单，准备出发 | 手机订单页、电动车、前车篮里的猫、后外卖箱 | 新手紧张但认真 | 第三人称正面中景 | 默认不分镜，作为绝对锚点 |
| 2 | 检查猫背带和装备 | 女生手扶猫背带、猫坐在前车篮、同一马甲和外卖箱 | 小心翼翼、有点手忙脚乱 | 近景，突出手部动作 | 不分镜 |
| 3 | 到店取餐 | 店门、取餐台或店员递出外卖袋、订单号或取餐牌 | 专注确认 | 第三人称，店门环境清晰 | 可选第一人称 + 第三人称 |
| 4 | 路上配送 | 同一辆车、前车篮里的猫、后外卖箱、路面运动感 | 开始进入状态 | 低机位或侧前方跟拍 | 不分镜 |
| 5 | 到楼下找楼层 | 小区楼栋、手机导航/门牌、女生抬头确认、外卖袋在手 | 有点慌但努力确认 | 第三人称，楼栋信息可见 | 可选主画面 + 手机小视角 |
| 6 | 送达后轻松收束 | 门口/楼梯平台、外卖已送达、女生和猫短暂休息 | 松一口气、轻喜剧结尾 | 竖屏全身或半身收束图 | 不分镜 |

### 15.3 每张图必须同步生成文案

生成图片时必须同步输出每张图的文案清单，不能只生成空白气泡。

推荐字段：

```text
标题
女生气泡
猫咪气泡
旁白
评论引导
后期叠字建议位置
```

推荐示例：

| 张数 | 标题 | 女生气泡 | 猫咪气泡 | 评论引导 |

### 15.4 锚点图与连续性强制规则

第一张图必须作为本组故事的绝对锚点图。

后续 5 张必须强制沿用：

```text
原始人物身份参考图
原始猫咪身份参考图
第 1 张锚点图
上一张成图
当前张分镜目标
```

连续性锁定清单：

| 锁定项 | 要求 |
|---|---|
| 人物 | 同一张脸、圆框眼镜、深色长发和刘海稳定 |
| 猫咪 | 同一只白色银渐层猫，脸型、眼睛、毛色稳定 |
| 服装 | 同一套米色/浅色外卖马甲、白 T、深色裤子 |
| 电动车 | 同一辆浅色电动车，车头和车篮结构保持一致 |
| 前车篮 | 黑色网格前篮，猫的位置延续 |
| 后外卖箱 | 同一浅色后外卖箱，绑带和箱体比例稳定 |
| 猫背带 | 同一米色猫背带，黑边和贴片细节稳定 |
| 贴片细节 | 马甲、猫背带、外卖箱上的标识风格尽量一致 |

### 15.5 镜头语言与视觉证据要求

每张图只能推进一个明确剧情动作，避免单张图承担过多信息。

镜头变化要求：

```text
6 张图中至少包含 3 种镜头距离：全身/中景/近景
6 张图中至少包含 3 种视角：正面/侧前方/低机位或第一人称
同一构图不得连续出现 3 张以上
```

关键剧情必须由画面本身完成叙事：

| 剧情 | 必须出现的视觉证据 |
|---|---|
| 接单 | 手机订单页、订单提醒、女生确认手机 |
| 出发 | 车把、外卖箱、猫坐稳、准备骑行姿态 |
| 到店 | 店门、菜单、取餐台、外卖袋交接 |
| 路上 | 道路运动感、骑行姿态、外卖箱在车后 |
| 找楼 | 楼栋、门牌、手机导航、女生抬头确认 |
| 送达 | 门口、外卖袋送达、放松或休息动作 |

### 15.6 气泡与叠字规范

气泡默认仍允许为空白，但必须配套输出文案清单和叠字位置。

气泡规范：

```text
人物气泡靠近人物头部或上半身，不遮挡脸、眼镜、手部动作
猫咪气泡靠近猫头或前车篮，不遮挡猫脸和背带
气泡大小保持同组一致，长文案使用标题区或底部字幕区
气泡尾巴必须指向说话角色
顶部保留标题安全区，底部保留平台按钮/字幕安全区
```

### 15.7 生成后验收与返工提示词

每张图生成后必须进入验收，不通过时生成返工提示词。

| 验收项 | 通过标准 | 失败时返工方向 |
|---|---|---|
| 剧情清晰 | 不看文字也能看出本张动作 | 增加强视觉证据，减少无关背景 |
| 连续性 | 人、猫、服装、车、箱、背带与上一张一致 | 引用锚点图和上一张成图重新生成 |
| 单图动作 | 本张只表达一个核心动作 | 删除多余动作，聚焦单一剧情 |
| 情绪推进 | 新手紧张到完成后的放松有变化 | 调整表情、姿态、动作细节 |
| 镜头变化 | 与前后图构图不重复 | 改变机位、距离或视角 |
| 气泡可用 | 气泡位置合理，适合叠字 | 调整气泡大小、位置和尾巴方向 |
| 文案完整 | 标题、女生、猫咪、评论引导齐全 | 重新生成对应文案 |

通用返工提示词模板：

```text
请基于第 1 张锚点图和上一张成图重新生成第 {n} 张。
必须保持同一个女生、同一只白色银渐层猫、同一套米色外卖马甲、同一辆电动车、同一前车篮、同一后外卖箱、同一猫背带。
本张只表达一个动作：{本张剧情动作}。
画面必须出现这些视觉证据：{视觉证据清单}。
不要重复上一张构图，镜头改为：{镜头建议}。
保留可叠字的空白气泡，气泡不要遮挡人脸、猫脸和关键动作。
```
