# 人猫搭档 AIGC 项目 V1.7 NEW 入口实施方案

> 日期：2026-07-03  
> 范围：保留旧入口，修正 `入口_NEW.html` 的功能对齐问题，并保留完整 Prompt 预览。

## 1. 目标

在不替换旧入口、不修改 Python 生成脚本公共接口的前提下，让 `入口_NEW.html` 作为新版视觉入口可用：

- 保留 NEW 的像素风界面样式。
- 输出的最小入参 JSON 与 V1.7 schema / `tools/generate_prompt.py` 对齐。
- 保留“完整 Prompt”标签页，用作前端预览和沟通稿。
- 旧入口 `入口_开始这里.html` 继续作为稳定入口保留。

## 2. 不做范围

```text
不删除旧入口
不修改 Python 脚本命令行参数
不修改 schema 字段名
不引入前端框架
不把前端 Prompt 预览等同于最终脚本产物
```

## 3. 实施内容

### 3.1 字段枚举对齐

将 NEW 入口中的字段值统一改为脚本可识别的值：

| 字段 | 对齐后 |
|---|---|
| `story_template` | `自动判断` / `外卖跑单故事` / `居家治愈故事` |
| `output_mode` | `单张大图` |
| `ratio` | `4:3` / `9:16` |
| `platform` | `通用` / `抖音竖屏` |
| `text_mode` | `无文字` / `直接生成文字` / `空白气泡后期加字` |
| `text_render_mode` | 脚本内四种 V1.7 文字落地模式 |
| `outfit_style_lock` | `不锁定` / `弱锁定` / `强锁定` |
| `outfit_reference` | 脚本内五种服装参考来源 |
| `storyboard_view` / `storyboard_layout` | 与脚本常量一致 |

### 3.2 常用模板

保留旧入口能力：

- 内置外卖连续故事模板。
- 内置居家治愈故事模板。
- 支持保存自定义模板到浏览器本地。
- 支持删除自定义模板。
- 支持恢复内置模板。

### 3.3 真实校验

NEW 入口校验区不再写死“全部通过”，而是根据当前 JSON 执行前端校验：

- 必填字段是否完整。
- `image_count` 是否在 1-12。
- 枚举值是否与脚本一致。
- 校验失败时直接展示失败项。

### 3.4 完整 Prompt 保留方式

继续保留“完整 Prompt”标签页，但定位为：

```text
前端预览版完整 Prompt
```

原因：

- 最终可追踪产物仍应由 `tools/generate_prompt.py --input` 生成。
- Python 会输出 `story_plan.json`、`frame_plan.json`、`copy_plan.json`、`prompt_plan.json`、`qa_result.json` 和 `retake_prompt.json`。
- 前端预览主要用于快速沟通、复制方向和人工确认。

## 4. 验收标准

### P0 必验

| 编号 | 验收项 | 通过标准 |
|---:|---|---|
| P0-01 | 旧入口保留 | `入口_开始这里.html` 未修改 |
| P0-02 | NEW 默认 JSON 可用 | 默认外卖模板生成的 JSON 可被 `tools/generate_prompt.py --input` 接受 |
| P0-03 | 枚举一致 | NEW 不再输出脚本不识别的字段值 |
| P0-04 | 模板可用 | 外卖 / 居家模板能切换并刷新 JSON |
| P0-05 | 完整 Prompt 保留 | `完整 Prompt` 标签页仍可生成动态预览 |
| P0-06 | 校验真实 | 字段错误时校验区展示失败项 |

### P1 推荐

| 编号 | 验收项 | 通过标准 |
|---:|---|---|
| P1-01 | 自定义模板 | 浏览器本地可保存 / 删除自定义模板 |
| P1-02 | 张数变化 | 3 / 5 / 6 / 8 / 12 张时 Prompt 预览顺序随之变化 |
| P1-03 | 居家模板 | 居家模板不再输出外卖分镜 |

## 5. 使用方式

1. 打开 `入口/入口_NEW.html`。
2. 选择内置模板或自定义模板。
3. 填写 `故事情节` 和 `补充说明`。
4. 复制 `最小入参 JSON`。
5. 保存为 JSON 文件后运行：

```bash
python tools/generate_prompt.py --input <你的输入文件.json>
```

6. 以脚本生成的 pipeline 目录作为最终执行产物。

## 6. 风险与控制

| 风险 | 控制 |
|---|---|
| 前端 Prompt 与 Python 最终 Prompt 不完全一致 | 前端明确标注为预览版，最终以脚本输出为准 |
| 用户误把 NEW 直接设为唯一入口 | 旧入口保留，README / START_HERE 后续再决定是否切换 |
| 浏览器本地模板丢失 | 自定义模板只作为便捷能力，核心输入仍可复制 JSON 保存 |

## 7. 结论

NEW 入口适合作为新版视觉入口继续推进；本期重点是让它先满足 V1.7 输入与预览需求。是否替换旧入口，应在默认 JSON 跑通 Python 流水线、真实图片 M5 验收完成后再决定。
