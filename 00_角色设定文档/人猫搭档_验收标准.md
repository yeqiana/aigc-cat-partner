# 人猫搭档_验收标准

## 1. 总体验收原则

每张图不是单独看好不好看，而是看它能否进入「人猫搭档资产库」。

必须满足：

1. 看起来是同一个女生。
2. 看起来是同一只白色银渐层猫。
3. 风格统一为真实生活摄影 / 拍立得质感。
4. 场景变化后，角色视觉基因不丢失。
5. 没有明显肢体、文字、服装、光影错误。

## 2. 单图验收表

| 验收项 | 通过标准 | 结论 |
|---|---|---|
| 人脸一致 | 一眼看出是同一个女生 | 通过 / 条件通过 / 不通过 |
| 猫脸一致 | 一眼看出是同一只银渐层猫 | 通过 / 条件通过 / 不通过 |
| 眼镜稳定 | 圆框眼镜没有消失或严重变形 | 通过 / 条件通过 / 不通过 |
| 发型稳定 | 长深色头发和刘海没有大改 | 通过 / 条件通过 / 不通过 |
| 猫品种稳定 | 白色银渐层、圆脸、大眼稳定 | 通过 / 条件通过 / 不通过 |
| 表情自然 | 不僵硬，不夸张，不网红化 | 通过 / 条件通过 / 不通过 |
| 服装合理 | 服装符合本次场景，图案不乱 | 通过 / 条件通过 / 不通过 |
| 动作自然 | 抱猫、骑车、取餐、爬楼等动作合理 | 通过 / 条件通过 / 不通过 |
| 场景真实 | 沙发、绿植、街道、楼道光影自然 | 通过 / 条件通过 / 不通过 |
| 系列统一 | 多张放一起像同一个故事系列 | 通过 / 条件通过 / 不通过 |

## 3. 返工标准

| 问题 | 处理 |
|---|---|
| 人脸明显不像 | 直接返工 |
| 猫明显不像 | 直接返工 |
| 眼镜消失 | 直接返工 |
| 猫变成其他品种 | 直接返工 |
| 人或猫比例严重错误 | 直接返工 |
| 手部轻微瑕疵但不影响主体 | 条件通过，可后期修 |
| 背景小瑕疵 | 条件通过，可裁切或修图 |
| 衣服图案乱码 | 局部重绘或返工 |
| 整体风格不真实 | 返工 |

## 4. 入库等级

| 等级 | 标准 | 去向 |
|---|---|---|
| S | 人猫一致性强，构图好，可直接发布 | 06_最终可用图 |
| A | 基本可用，有轻微瑕疵 | 06_最终可用图/待修 |
| B | 人猫基本像，但动作或细节一般 | 对应资产目录/备用 |
| C | 变脸、变猫、明显崩坏 | 不入库 |

## V1.2 气泡与文字验收

| 验收项 | 通过标准 |
|---|---|
| 无气泡无文字 | 画面没有额外气泡、字幕、标题贴纸和乱码文字 |
| 空白气泡 | 气泡干净留白，方便后期加字 |
| 直接生成文字 | 文字短、清楚、不乱码，不出现多余字符 |
| 气泡位置 | 不遮挡女生脸、猫脸、眼镜、手部和主体动作 |
| 风格一致 | 气泡像真实贴纸/轻量设计，不把图片变成漫画风 |
| 抖音竖屏 | 顶部标题区和底部字幕区安全，不裁切主体 |
