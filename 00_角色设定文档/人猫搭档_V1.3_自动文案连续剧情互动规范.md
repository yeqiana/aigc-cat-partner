# 人猫搭档 V1.3 自动文案 / 连续剧情 / 观众互动规范

## 1. 本次修复点

V1.3 解决三个问题：

1. **文字可以自动根据情节生成**：不再必须手填 `human_text` / `cat_text` / `title_text`。
2. **抖音竖屏可以选择生成几张**：`image_count` 支持 1-12。
3. **支持连续情节**：`continuous_story=是` 时，会把漫画式剧情拆成一张一张的 9:16 大图。
4. **支持观众互动**：可选择不互动、看向观众、提问互动、评论引导、点赞关注、选择投票。

---

## 2. 自动文案规则

新增字段：

```json
{
  "copywriting_mode": "自动根据情节生成"
}
```

当选择自动生成时，系统会根据：

- 场景 `scene`
- 动作 `action`
- 氛围 `mood`
- 是否连续剧情 `continuous_story`
- 观众互动模式 `interaction_mode`

自动生成：

| 字段 | 用途 |
|---|---|
| `title_text` | 顶部标题 / 旁白标题 |
| `human_text` | 女生气泡文案 |
| `cat_text` | 猫咪气泡文案 |

推荐仍然使用：

```json
{
  "text_mode": "空白气泡后期加字"
}
```

因为图片模型直接生成中文容易乱码。最稳流程是：**自动生成文案建议 + 图片只出空白气泡 + 后期手动加字**。

## 3. 抖音竖屏多张大图规则

新增字段：

```json
{
  "ratio": "9:16",
  "platform": "抖音竖屏",
  "image_count": 5,
  "continuous_story": "是"
}
```

### 3.1 连续情节 = 是

用于把漫画拆成多张竖屏大图：

| 第几张 | 默认剧情 |
|---|---|
| 1 | 出发 |
| 2 | 取餐 |
| 3 | 骑车路上 |
| 4 | 爬楼送达 |
| 5 | 疲惫休息 |
| 6 | 回家收工 |

每一张都是独立 9:16 大图，不是拼图。

### 3.2 连续情节 = 否

用于生成同主题多张变体：

- 同一个场景
- 同一个人物和猫
- 不同角度
- 不同站位
- 不同背景虚化
- 不形成剧情前后关系

---

## 4. 观众互动规则

新增字段：

```json
{
  "interaction_mode": "提问互动"
}
```

可选值：

| 模式 | 用途 |
|---|---|
| 不互动 | 纯生活照，不引导用户 |
| 看向观众 | 人或猫看镜头，像邀请观众进入画面 |
| 提问互动 | 标题/气泡出现简短问题 |
| 评论引导 | 引导观众评论餐名、经历、选择 |
| 点赞关注 | 轻度关注引导，适合账号内容 |
| 选择投票 | A/B 选择，让用户决定下一步剧情 |

## 5. 推荐组合

### 抖音图文剧情最稳组合

```json
{
  "scene": "送外卖正面",
  "ratio": "9:16",
  "platform": "抖音竖屏",
  "image_count": 5,
  "continuous_story": "是",
  "bubble_mode": "双气泡",
  "text_mode": "空白气泡后期加字",
  "copywriting_mode": "自动根据情节生成",
  "interaction_mode": "评论引导"
}
```

### 单张互动封面

```json
{
  "scene": "爬楼疲惫",
  "ratio": "9:16",
  "image_count": 1,
  "bubble_mode": "旁白标题",
  "text_mode": "空白气泡后期加字",
  "copywriting_mode": "自动根据情节生成",
  "interaction_mode": "选择投票"
}
```

## 6. 验收标准补充

| 验收项 | 通过标准 |
|---|---|
| 自动文案 | 文案符合画面情节，不突兀 |
| 多张大图 | 每一张都是独立 9:16，不是拼图 |
| 连续剧情 | 前后有故事顺序，但每张单独成立 |
| 观众互动 | 互动自然，不像硬广 |
| 气泡位置 | 不遮挡人脸、猫脸、眼镜、动作 |
| 中文文字 | 直接出字不能乱码；不稳时用空白气泡后期加字 |
