# 人猫搭档_气泡文字规范 V1.2

## 1. 目标

让图片可以按需求选择：

1. 完全无气泡、无文字。
2. 有人物气泡。
3. 有猫咪气泡。
4. 有双气泡。
5. 有标题/旁白贴纸。

## 2. 默认策略

默认不生成气泡和文字，因为母版图和资产图需要保持干净。

正式运营封面如果需要文案，推荐使用：

```text
空白气泡后期加字
```

原因：AIGC 模型生成中文容易乱码，后期加字更稳定，也方便统一字体、字号和位置。

## 3. 字段说明

| 字段 | 可选值 | 说明 |
|---|---|---|
| bubble_mode | 无 / 人物气泡 / 猫咪气泡 / 双气泡 / 旁白标题 | 控制画面是否出现气泡或标题贴纸 |
| text_mode | 无文字 / 直接生成文字 / 空白气泡后期加字 | 控制是否把文字直接画进图里 |
| text_position | 自动 / 顶部标题区 / 人物旁边 / 猫咪旁边 / 底部字幕区 | 控制气泡或文字位置 |
| human_text | 12 字以内 | 女生气泡文字 |
| cat_text | 12 字以内 | 猫咪气泡文字 |
| title_text | 12 字以内 | 标题或旁白文字 |

## 4. 推荐组合

| 使用目的 | 推荐配置 |
|---|---|
| 母版图 | bubble_mode=无，text_mode=无文字 |
| 抖音封面 | bubble_mode=旁白标题，text_mode=空白气泡后期加字 |
| 搞笑剧情图 | bubble_mode=猫咪气泡，text_mode=空白气泡后期加字 |
| 对话剧情 | bubble_mode=双气泡，text_mode=空白气泡后期加字 |
| 快速草稿 | bubble_mode=双气泡，text_mode=直接生成文字 |

## 5. 验收标准

- 气泡不能遮挡女生脸、猫脸、眼镜、手部和核心动作。
- 如果选择无气泡无文字，画面里不能出现额外字幕、标题、贴纸文字。
- 如果选择空白气泡后期加字，气泡必须干净留白。
- 如果选择直接生成文字，文字不能乱码，不能出现多余字符。
- 气泡风格要符合真实生活照片，不要变成漫画风。
