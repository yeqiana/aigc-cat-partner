# 人猫搭档_跨会话一致性修复说明 V1.1

## 已修复的问题

### 问题 1：当前会话稳定，新会话变脸/换猫

原因：当前会话里模型会记住前面刚生成的图和参考图；切换新会话后，只剩文字 Prompt，模型会重新想象人物和猫，所以会漂移。

修复方案：新增 `99_跨会话身份锁定包/`。

每次新会话必须先上传：

1. `R01_human_identity_ref.jpg`
2. `R02_cat_identity_ref_front.jpg`
3. `R03_cat_identity_ref_close.jpg`

然后根据场景再上传一张母版图，例如：

- 沙发绿植：`M01_sofa_green_front_4x3.png`
- 送外卖：`M03_delivery_front_4x3.png`

Prompt 中新增了【跨会话身份锁定】区块，要求原始人像图和猫图优先级高于文字描述。

### 问题 2：需要可以生成单独大图，比例为抖音竖屏

修复方案：入口和脚本都新增：

- `output_mode`: 单张大图 / 多镜头拼图
- `ratio`: 4:3 / 9:16
- `platform`: 通用 / 抖音竖屏

当选择 `单张大图 + 9:16 + 抖音竖屏` 时，Prompt 会自动写入：

- 只生成一张完整大图
- 不要拼图、不要多宫格
- 抖音竖屏 9:16
- 主体居中偏上
- 预留顶部标题安全区和底部字幕安全区
- 适合短视频封面

## 新会话标准流程

```text
Step 1：打开 99_跨会话身份锁定包
Step 2：上传 3 张原始参考图
Step 3：根据场景上传 1 张母版图
Step 4：打开 入口/入口_开始这里.html
Step 5：选择场景、角度、动作、服装、输出模式、比例
Step 6：复制 Prompt 出图
Step 7：按验收标准筛选
```

## 关键原则

不要试图用纯文字实现跨会话完全一致。稳定人物和猫，需要“参考图 + 视觉基因 + 母版图 + Prompt”四件套。
