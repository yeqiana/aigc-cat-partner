# 人猫搭档_视觉基因表

## 1. 项目基础定位

| 项目 | 内容 |
|---|---|
| 项目名称 | 人猫搭档 |
| 角色组合 | 年轻女生 + 白色银渐层猫 |
| 风格 | 写实生活摄影风 |
| 画面质感 | 接近拍立得、轻微颗粒、自然光、低饱和 |
| 主要用途 | 小红书图文、短视频封面、剧情图、表情包、IP资产 |
| 默认比例 | 4:3 |

## 2. 女生固定视觉基因

| 维度 | 固定内容 | 可变化内容 | 禁止变化 |
|---|---|---|---|
| 年龄感 | 年轻女生，20 多岁 | 妆容轻微变化 | 不要成熟御姐化、不要幼态化 |
| 脸部 | 清秀自然、小脸、柔和五官 | 轻微角度变化 | 不要网红脸、欧美脸、明星脸 |
| 眼镜 | 大圆框眼镜、细边框 | 镜片轻微反光 | 眼镜不能消失，不能变成方框 |
| 发型 | 深色长发、有刘海、自然蓬松 | 发丝方向、轻微凌乱 | 不要短发、染发、夸张发型 |
| 表情 | 安静、略认真、自然 | 轻微微笑、疲惫、专注 | 不要夸张大笑、鬼脸、强烈情绪 |
| 体型 | 偏瘦、肩窄、自然生活状态 | 坐姿、站姿、骑车姿势 | 不要明显变胖变壮 |
| 气质 | 安静、清冷、温柔、日常感 | 根据场景微调 | 不要性感化、夸张商业模特化 |

## 3. 猫固定视觉基因

| 维度 | 固定内容 | 可变化内容 | 禁止变化 |
|---|---|---|---|
| 品种感 | 白色银渐层 / 英短银渐层感 | 毛发光影变化 | 不要橘猫、布偶、长毛猫 |
| 脸型 | 圆脸、脸颊饱满 | 表情轻微变化 | 不要尖脸、瘦脸 |
| 眼睛 | 超大圆眼、深色偏绿/灰 | 眼神方向 | 不要小眼睛、异色瞳 |
| 毛色 | 白色为主，头顶淡银灰纹理 | 光线导致的冷暖变化 | 不要纯黑、橘色、花猫 |
| 表情 | 呆萌、认真、好奇 | 疲惫、疑惑、轻微开心 | 不要过度拟人笑 |
| 体型 | 圆润但真实猫比例 | 坐姿、趴姿、被抱 | 不要人形身体 |

## 4. 色彩体系

| 类型 | 颜色倾向 | 用途 |
|---|---|---|
| 主色 | 奶油白 / 米白 | 人物衣服、猫衣服、整体基调 |
| 辅色 | 浅咖 / 浅灰 / 黑色边线 | 沙发、外卖马甲、外卖箱 |
| 点缀色 | 绿植绿色 / 猫眼绿色 | 背景和记忆点 |
| 禁用色 | 高饱和荧光色、大红大紫 | 避免破坏生活感 |

## 5. 固定画面气质

```text
整体气质：真实、日常、安静、温馨、轻微搞笑
光影风格：自然光、柔和阴影、不过曝
背景复杂度：有生活细节，但不抢主体
材质风格：真实布料、真实猫毛、真实沙发/街道/楼道材质
镜头语言：中景、半身、正面/45度优先
构图习惯：人和猫都清晰，主体居中或偏中心
后期质感：拍立得质感，轻微颗粒噪点，低饱和
```
