# 9宫格漫画分镜 Prompt 套装

> 适用目标：把小说章节转成“9 张连续漫画分镜图”。  
> 推荐比例：竖屏连载 `9:16` / 单格 `4:5` / 漫画页 `2:3`。  
> 核心原则：每格只讲一个动作或一个情绪，不要一格塞太多剧情。

---

## 0. 统一分镜风格母 Prompt

```text
韩漫 / 国漫半写实厚涂风格，电影感漫画分镜，高完成度插画，细腻人物表情，真实布料褶皱，柔和皮肤质感，低饱和色彩，冷暖对比光影，情绪克制，镜头叙事清晰，画面有连续漫画感，同一组人物保持五官、发型、肤色、身材比例和服装风格一致。
```

英文：

```text
Korean webtoon style, high-end Chinese manhua illustration, semi-realistic painterly rendering, cinematic comic panel, emotional storytelling, refined character expressions, realistic fabric folds, soft skin shading, low-saturation palette, warm-cool lighting contrast, consistent recurring characters across panels.
```

## 1. 9宫格结构说明

| 格子 | 功能 | 典型镜头 |
|---|---|---|
| 01 | 建立场景 | 远景 / 全景 |
| 02 | 人物进入 | 中景 / 侧面 |
| 03 | 事件触发 | 动作特写 |
| 04 | 情绪反应 | 脸部特写 |
| 05 | 关系推进 | 双人半身 |
| 06 | 冲突或转折 | 近景 / 压迫构图 |
| 07 | 安静余波 | 留白 / 背影 |
| 08 | 道具记忆点 | 手部 / 物品特写 |
| 09 | 章节收束 | 电影感定格 |

## 2. 通用 9宫格 Prompt 模板

### 第 1 格：场景建立

```text
【第1格 / 建立场景】
生成一张漫画分镜图。场景是【地点】，时间是【季节 / 时间段】，天气是【天气】。镜头为远景或全景，先展示环境，不强调人物表情。画面要有电影感和叙事氛围，低饱和色彩，细节包括【关键道具1】、【关键道具2】、【环境声音或气味暗示】。韩漫 / 国漫半写实厚涂风格，保持后续系列风格统一。
```

### 第 2 格：人物进入

```text
【第2格 / 人物进入】
生成一张漫画分镜图。角色【人物A】进入【场景】，动作是【动作】，角色状态是【情绪】。镜头为中景，人物位于画面三分之一位置，背景保留足够环境信息。光影延续第1格，人物五官、发型、服装保持与母版一致。
```

### 第 3 格：事件触发

```text
【第3格 / 事件触发】
生成一张漫画分镜图。画面表现【关键事件】发生的瞬间，镜头聚焦手部、道具或身体动作，例如【被抢走的牛奶 / 被握住的手 / 掉落的物品 / 推开的门】。构图紧凑，有动作感，但不要夸张漫画化。半写实厚涂，电影分镜感。
```

### 第 4 格：情绪反应

```text
【第4格 / 情绪反应】
生成一张漫画分镜图。角色【人物A】对刚才事件产生情绪反应，镜头为脸部近景或半身特写。重点表现眼神、嘴唇、手部小动作。背景略微虚化。情绪是【害怕 / 震惊 / 克制 / 心疼 / 疏离 / 想靠近又不敢】。保持人物一致性。
```

### 第 5 格：双人关系推进

```text
【第5格 / 双人关系】
生成一张漫画分镜图。角色【人物A】和【人物B】同框，动作是【牵手 / 护在身前 / 低头对视 / 递东西 / 站在身侧】。镜头为双人半身，构图强调两人距离和关系。人物气质对比明显：一个【柔软 / 敏感 / 空眼神】，一个【沉默 / 冷淡 / 保护姿态】。
```

### 第 6 格：冲突或转折

```text
【第6格 / 冲突转折】
生成一张漫画分镜图。画面表现本章核心转折：【冲突事件】。镜头更近，构图有压迫感，人物表情克制但情绪强烈。光影对比增强，局部暖光照亮面部或手部，背景变暗，营造紧张感。
```

### 第 7 格：安静余波

```text
【第7格 / 安静余波】
生成一张漫画分镜图。事件结束后的安静一刻，角色【人物A】处在【位置】，动作很小，例如低头、侧耳、抱毯子、背影、站在门口。镜头有留白，背景氛围明显，情绪是沉默、后怕、孤独、温柔或释然。
```

### 第 8 格：道具记忆点

```text
【第8格 / 道具记忆点】
生成一张漫画分镜图。画面聚焦本章关键道具【小毯子 / 牛奶杯 / 冰溜子 / 枕巾 / 盲杖 / 奶茶 / 手机录音 / 吉他】。镜头为手部或物品特写，道具要和人物情绪连接。光影细腻，像漫画中的记忆定格。
```

### 第 9 格：章节收束

```text
【第9格 / 章节收束】
生成一张漫画分镜图。用一个电影感定格收束本章。角色【人物A】和【人物B】处于【最终位置】，关系状态是【靠近 / 分开 / 牵手 / 沉默并肩 / 一人回头】。镜头为中远景或半身定格，画面有余韵，像章节结尾插图。
```

## 3. 示例套装 A：第1章“寒冬初遇”9宫格

### 01 建立场景：农村灵棚

```text
【第1格 / 建立场景】
北方农村寒冬腊月，陶家老屋院子，灵棚搭在院中，白布、纸钱、火盆、厚雪、敞开的院门，风吹动布幔。远景全景，冷灰蓝色调，火盆有一点微弱暖光，纸灰味和寒风感。韩漫 / 国漫半写实厚涂，电影感漫画分镜。
```

### 02 陶淮南在灵棚前

```text
【第2格 / 人物进入】
陶淮南8岁，奶白小圆脸，黑色柔软短发，戴浅色毛线帽和厚围巾，穿米白色羽绒服，手里捧着牛奶杯，眼睛很大但没有聚焦。他站在灵棚前，身体缩着，听着周围声音，表情胆怯。中景，冷空气明显。
```

### 03 迟苦抢牛奶

```text
【第3格 / 事件触发】
迟苦8到9岁，瘦得明显，肤色偏黑黄，黑色短发，薄单眼皮，穿很破旧单薄的衣服，突然冲过来抢走陶淮南手里的牛奶。镜头聚焦两只小手和被夺走的牛奶杯，动作紧张，背景雪地虚化。
```

### 04 陶淮南被吓到

```text
【第4格 / 情绪反应】
陶淮南脸部近景，眼睛睁大但无焦点，嘴唇微张，手还保持着捧杯子的姿势，表情惊吓又茫然。浅色围巾包住半张脸，冷风吹起碎发。背景虚化成灰蓝雪地。
```

### 05 陶晓东出现

```text
【第5格 / 双人关系】
陶晓东25岁，高大有力，黑色短发，穿军绿色大衣和深色毛衣，快步走到陶淮南身边，把弟弟护在身前。陶淮南缩进哥哥身侧。镜头为双人半身，突出哥哥的保护感。
```

### 06 迟苦被追打的恐惧

```text
【第6格 / 冲突转折】
迟苦站在灵棚边缘，身体冻得发抖，眼神向下，既警觉又麻木。远处有醉酒男人模糊的影子追来。镜头中景，迟苦处在暗处，火盆暖光照到半边脸，形成冷暖对比。不要直接表现血腥。
```

### 07 陶晓东用大衣裹住迟苦

```text
【第7格 / 安静余波】
陶晓东蹲下，用大衣把冻僵的迟苦裹住。迟苦身体僵硬，低头不说话；陶淮南站在旁边，抱着小毯子，侧耳听。雪还在下，灵棚白布在风里动。画面安静，有救下他的转折感。
```

### 08 牛奶杯特写

```text
【第8格 / 道具记忆点】
雪地上的牛奶杯特写，杯口还有一点白色牛奶，旁边是纸灰和雪。远处模糊可见两个小孩和陶晓东的身影。物品特写，象征两人初遇。
```

### 09 寒冬三人定格

```text
【第9格 / 章节收束】
寒冬院门口，陶晓东站在中间，一边护着陶淮南，一边看向被大衣裹住的迟苦。陶淮南抱着小毯子，迟苦低头沉默。远景定格，灵棚、火盆、厚雪、敞开的院门共同形成故事起点。电影感收束图。
```

## 4. 示例套装 B：第7章“盲校第一天”9宫格

```text
01 盲校教室全景：低年级教室，一群孩子哭，阳光从窗户斜照进来，桌椅杂乱，老师在安抚。
02 陶淮南坐在小板凳上，抱着小毯子，眼睛无聚焦，害怕得发抖。
03 迟苦站在旁边，深色旧衣服，表情冷淡但没有走开。
04 陶淮南突然抓住迟苦的手，手部特写，指节用力。
05 迟苦低头看被抓住的手，没有挣开，双人半身。
06 教室哭声震天，迟苦显得格格不入，陶淮南死死攥着他。
07 宿舍夜晚，两张小床床头对床头，中间隔着床栏。
08 枕巾穿过栏杆，两端分别被两个孩子抓着，手部特写。
09 夜晚宿舍定格，两个孩子隔着床栏睡着，枕巾连接彼此，暖光安静。
```

完整可用 Prompt：

```text
请生成一组9宫格漫画分镜，主题是“盲校第一天”。风格为韩漫 / 国漫半写实厚涂，电影感分镜，低饱和，室内暖光。陶淮南8岁，奶白小圆脸，黑色柔软短发，大而无聚焦的眼睛，穿浅色衣服，抱小毯子，胆怯敏感；迟苦8到9岁，瘦，肤色偏黑黄，黑短发，薄单眼皮，穿深色旧衣服，沉默防备。九格依次表现：盲校教室全景、陶淮南害怕、迟苦站在旁边、陶淮南抓住迟苦的手、迟苦没有挣开、教室哭声中的二人、夜晚宿舍、枕巾穿栏杆的手部特写、两人隔着床栏睡着的收束画面。保持人物一致性，不要成人化，不要暧昧化儿童关系，只表现保护和依赖。
```

## 5. 示例套装 C：成年“雨夜重逢”9宫格

```text
01 云南医援点外景，夏末暴雨，偏远医疗站，车灯、雨水、山影。
02 成年陶淮南站在走廊，白色外套，眼睛无聚焦，侧耳听雨声。
03 成年迟骋从雨中回来，黑色雨衣，手上有纱布，表情冷淡。
04 陶淮南听见熟悉脚步声，脸部近景，表情克制但心乱。
05 两人在走廊近距离站定，迟骋低头，陶淮南微微仰头但视线空。
06 陶淮南伸手想碰迟骋手上的纱布，手停在半空。
07 迟骋侧身避开一点，情绪压抑，背景雨声很重。
08 走廊小灯和雨水特写，像未说出口的话。
09 两人一前一后走进昏暗宾馆走廊，距离不远但有隔阂。
```

完整可用 Prompt：

```text
请生成一组9宫格漫画分镜，主题是“成年后的雨夜重逢”。风格为韩漫 / 国漫半写实厚涂，电影感分镜，冷色雨夜环境，暖色走廊小灯。陶淮南22到25岁，白净，黑色柔软碎发，眼睛无聚焦，穿浅色外套，气质温和清透；迟骋23到25岁，高大修长，黑色短发，薄单眼皮，穿黑色雨衣或深色外套，气质冷淡压迫。九格依次表现：云南医援点暴雨外景、陶淮南在走廊听雨、迟骋从雨中回来、陶淮南听见熟悉脚步声、两人走廊对视、陶淮南想碰迟骋手上的纱布、迟骋克制避开、走廊灯和雨水特写、两人一前一后走入走廊的收束画面。保持人物一致性，突出重逢后的疏离、旧情、克制和拉扯。
```

## 6. 9宫格负向 Prompt

```text
低质量，脸崩，人物不一致，发型变化，年龄变化，服装变化，过度二次元，Q版，儿童成人化，暧昧化儿童关系，性感化，裸露，水印，文字乱码，对话框乱码，肢体错误，手指错误，多余人物，背景过乱，情绪夸张，表情崩坏，镜头重复，九格没有连续性。
```

## 7. 批量生成建议

- 第一次不要直接跑 126 章。
- 先选 3 个测试章节：第1章、第7章、第83章。
- 每章先生成文字分镜，再生成 9 张单格图。
- 不建议一次生成完整九宫格大图，因为人物一致性会更难控制。
- 推荐流程：`章节摘要 → 9格脚本 → 单格 prompt → 逐格出图 → 后期拼接`。
