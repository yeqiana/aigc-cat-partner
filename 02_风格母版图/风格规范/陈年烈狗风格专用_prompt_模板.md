# 《陈年烈狗 / 陈年烈苟》风格专用 Prompt 模板

> 适用：人物母版、场景母版、章节插图、漫画分镜、封面图。  
> 核心风格：韩漫 / 国漫半写实厚涂 + 现实生活质感 + 电影分镜情绪。  
> 注意：童年阶段只表现陪伴、保护、依赖，不表现暧昧或成人化。

---

## 1. 项目总 Prompt

```text
《陈年烈狗》风格漫画插图，韩漫 / 国漫高完成度半写实厚涂，电影感分镜，现实生活质感，低饱和色彩，冬日冷空气与室内暖光对比，人物情绪克制细腻，关系张力强但不低俗，画面像高质量漫画单页或电影剧照。人物五官、发型、肤色、身材比例和服装风格必须保持连续一致。
```

英文版：

```text
Chen Nian Lie Gou inspired comic illustration, Korean webtoon and high-end Chinese manhua style, semi-realistic painterly rendering, cinematic storyboard composition, realistic slice-of-life atmosphere, low-saturation color palette, winter cold air contrasted with warm indoor light, restrained and delicate emotions, strong relationship tension without vulgarity, like a high-quality comic page or movie still. Keep characters consistent in face, hairstyle, skin tone, body proportions, and outfit design.
```

## 2. 世界观风格锁定

### 2.1 色彩

```text
低饱和，冬日灰蓝，旧棕，米白，暖黄灯光，深灰棉服，老房子木色，雪地冷白，雨夜深蓝，清吧暖金色，医院冷白光。
```

### 2.2 质感

```text
真实布料褶皱，羽绒服蓬松感，旧墙皮，老家具，火炕，暖气片，学校铁床栏杆，纸灰，雪，雨水，玻璃反光，台灯暖光，皮肤柔和阴影，头发细节清晰。
```

### 2.3 情绪

```text
寒冷、陌生、保护、依赖、沉默、克制、拉扯、分离、重逢、和解、温柔、余韵。
```

## 3. 主角视觉基因

### 3.1 陶淮南

```text
陶淮南，失明，眼睛大而黑亮但没有明确聚焦，视线空，皮肤白净，五官漂亮干净，黑色柔软短发。童年时期奶白小圆脸，抱浅色小毯子，穿米白羽绒服和毛线帽；少年时期清瘦敏感，穿浅色校服或毛衣；青年时期温和清透，穿格子衬衫、白色短袖、浅色外套，可带盲杖或吉他。性格外柔内韧，敏感、聪慧、黏人又逐渐独立。
```

### 3.2 迟骋 / 迟苦

```text
迟骋，原名迟苦，童年来自北方农村，瘦，肤色偏黑黄，黑色短发，薄单眼皮，眼神向下，沉默防备，穿深色旧棉服；少年时期高瘦，眉眼冷，保护欲强，穿深色校服或黑色卫衣；青年时期高大修长，黑短发，薄单眼皮，眉眼锋利，穿黑色高领毛衣和深色外套，科技创业者气质。性格沉默寡言、凶狠忠诚、内心温柔。
```

### 3.3 陶晓东

```text
陶晓东，25岁起承担家庭责任的哥哥，纹身师，黑色短发，高大有力，五官成熟利落，气质外糙内细、靠谱、护短、带一点痞气。穿军绿色大衣、黑色毛衣、深色工装裤，手臂可有纹身。动作常是抱弟弟、牵孩子、蹲下说话、在纹身工作室画图。不要画成霸总或过度精致偶像男主。
```

### 3.4 汤索言

```text
汤索言，眼科医生，成熟温和，比陶晓东略年长，气质从容、强大、干净，黑色或深棕短发，戴细框眼镜或无框眼镜，穿白大褂、浅色衬衫或干净毛衣。表情温和但有稳定气场，像家里最镇定的人。
```

### 3.5 十爷爷

```text
十爷爷，一只很老的金毛犬，暖金色长毛，体型大，动作慢，眼神温和，陪伴感强，常常趴在陶淮南旁边或沙发边。不要画成幼犬，不要卡通化。
```

## 4. 核心场景母版 Prompt

### 4.1 农村老家 / 灵棚 / 初遇

```text
北方农村寒冬腊月，陶家老屋院子，灵棚、白布、纸钱、火盆、厚雪、敞开的院门，风吹动布幔，地上有纸灰和雪。冷灰蓝色调，火盆提供微弱暖光，空气寒冷刺骨。画面像故事起点，带有死亡、陌生和命运相遇的氛围。韩漫 / 国漫半写实厚涂，电影感远景或中景。
```

### 4.2 火炕老屋

```text
北方农村老屋内部，火炕烧得很热，窗户漏风，窗框结冰，房间昏黄，墙面旧，炕革带柴火味。两个小孩在炕上保持距离，一个抱着小毯子，一个缩在炕边，室内暖光和窗外冷光对比强烈。半写实厚涂，电影感室内分镜。
```

### 4.3 陶晓东城市楼房

```text
普通城市两室两厅，暖气充足，客厅有沙发、旧茶几、窗外路灯黄光、阳台、盆栽、书本和生活杂物。傍晚暖光照进屋里，十爷爷趴在沙发边，画面温馨但带一点孤独。适合作为陶淮南、迟骋、陶晓东三人一狗的家庭主场景。韩漫 / 国漫半写实厚涂，生活质感，低饱和。
```

### 4.4 盲校教室 / 宿舍

```text
盲校低年级教室，普通桌椅，孩子们哭闹，老师安抚，窗外阳光斜照，画面带陌生和分离焦虑。宿舍有铁床栏杆，两张小床床头相对，中间用枕巾穿过栏杆连接，夜晚暖黄灯光安静。核心道具是枕巾、盲杖、盲文课本、小手机。半写实厚涂，电影感校园分镜。
```

### 4.5 普通初中

```text
普通初中教室、水房、走廊，暖气片、瓷砖地面、旧课桌、黑板、校服、课本。环境真实，不要贵族学校感。氛围包含融合教育中的不适应、保护、校园冲突和成长。色调偏秋冬，冷白自然光和室内暖光混合。
```

### 4.6 陶晓东纹身工作室

```text
居民楼一楼的纹身工作室，墙上挂着纹身图稿，桌上有画稿、纹身机、颜料瓶、台灯、皮椅、消毒工具，窗外是普通街道。整体不是奢华工作室，而是有烟火气、手艺人质感的空间。暖色台灯照亮桌面，背景略暗。陶晓东在桌前画图，两个孩子在旁边休息或看着。
```

### 4.7 老房子 / 共同回忆空间

```text
旧小区老房子，两人长大的房间，旧墙皮、旧沙发、暖气片、老电视、旧木柜、泛黄窗帘、桌上有茶杯和糖锅。冬天房间不够暖，光线昏黄，满屋有旧家具和熬糖的甜味。这个空间承载童年、分离、疼痛与和解，画面要有沉重记忆感和温柔余韵。
```

### 4.8 云南医援点 / 宾馆

```text
偏远山区医援点，夏末初秋，白天太阳很烈，尘土、临时医疗桌、药箱、人群、山影；夜晚突然暴雨，雨水砸在车顶和屋檐，宾馆走廊昏暗，小灯暖黄。氛围是成年重逢后的紧张、疏离和试探。半写实厚涂，电影感雨夜分镜。
```

### 4.9 北京高校 / 宿舍

```text
北京冬天的高校校园，干冷，雪地，教学楼，宿舍门口，拉杆箱，路灯，玻璃门反光。迟骋宿舍简洁理工男风格，有电脑、书、项目资料、手环原型设备。氛围是追回、等待、克制和重新靠近。
```

### 4.10 清吧 / 小酒馆

```text
小清吧，暖黄色小舞台灯，木质吧台，玻璃杯，观众坐得很远，背景昏暗，舞台上有吉他和麦克风。陶淮南坐在高脚凳上弹吉他唱歌，迟骋坐在台下看他。整体氛围温柔、从容、圆满，像故事结尾的电影定格。
```

## 6. 章节图通用拼装公式

```text
【项目风格】
《陈年烈狗》韩漫 / 国漫半写实厚涂，电影感漫画分镜，低饱和，冷暖对比，生活质感。

【时间阶段】
童年 / 少年 / 成年重逢 / 和解结局。

【角色】
陶淮南：对应年龄视觉基因。
迟骋：对应年龄视觉基因。
陶晓东 / 汤索言 / 十爷爷：按需加入。

【场景】
农村老家 / 城市楼房 / 盲校 / 初中 / 纹身店 / 老房子 / 云南医援 / 北京高校 / 清吧。

【动作】
牵手 / 抱毯子 / 递奶茶 / 侧耳听 / 保护 / 对视 / 背影 / 弹吉他。

【镜头】
远景建立场景 / 中景关系 / 近景情绪 / 手部道具特写 / 电影定格。

【光影】
冬日冷蓝 + 室内暖黄 / 雨夜深蓝 + 走廊暖灯 / 清吧暖金色舞台灯。

【一致性】
保持所有角色五官、发型、服装、年龄和气质统一。
```

## 7. 项目通用负向 Prompt

```text
低质量，模糊，水印，文字乱码，logo，脸崩，五官不一致，人物年龄错误，发型变化，肤色变化，服装变化，身体比例错误，手指错误，多余肢体，过度二次元，Q版，网红脸，霸总滤镜，过度偶像剧，儿童成人化，儿童暧昧，性感化，裸露，暴力血腥直白，陶淮南眼神聚焦正常，迟骋画得太白太精致，陶晓东画成霸总，十爷爷画成幼犬，背景不符合中国生活场景。
```
