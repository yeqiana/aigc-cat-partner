# 双男主固定角色卡 Prompt 成品版

> 适用项目：《陈年烈狗 / 陈年烈苟》AIGC 漫画分镜、人物母版、章节插图生成。  
> 目标：锁定陶淮南与迟骋的视觉基因，让他们在不同年龄、场景、镜头中保持“同一组人物”。  
> 推荐用法：先生成单人母版，再生成双人关系图，最后用于章节分镜。

## 1. 角色 A：陶淮南固定角色卡

### 1.1 陶淮南 · 童年版 8-12 岁

```text
陶淮南，8到12岁的中国男孩，四岁失明，皮肤奶白，脸型软圆，五官漂亮但不张扬，黑色柔软短发，眼睛很大、黑亮、水润，但视线没有明确聚焦，眼神带空感。身形偏小，软乎乎，有被照顾得很好的干净感。性格表现为胆小、敏感、黏人、乖巧，常常抱着浅色小毯子，或者用手摸索周围环境。穿米白色羽绒服、浅色毛线帽、厚围巾、宽松冬裤，整体像冬天里被保护得很好的小孩。
```

#### 童年版必须固定的视觉基因

```text
奶白肤色，小圆脸，黑色柔软短发，大而无聚焦的眼睛，浅色厚冬装，浅色小毯子，胆怯又乖的表情，手部有摸索感。
```

#### 童年版禁止偏移

```text
不要画成眼神聚焦正常的孩子；不要画成过度卖萌的幼儿；不要画成普通二次元大眼萌；不要成人化；不要暧昧化儿童关系；不要改变成金发、彩发或潮流发型。
```

## 3. 双男主关系固定模板

### 3.1 童年关系：陪伴 / 保护 / 依赖

```text
陶淮南主动靠近，手里抱着小毯子，眼神没有聚焦，表情害怕或好奇；迟骋站在他旁边或前方，表情冷淡，身体略微挡在陶淮南前面，嘴上不亲近但动作上保护他。两人的关系是童年陪伴和保护，不暧昧，不成人化。
```

### 3.2 少年关系：亲密但克制 / 青春期张力

```text
陶淮南站在迟骋身侧，微微侧头听他说话，手指抓住迟骋的袖口或书包带；迟骋表情冷淡但没有挣开，身体保持保护姿态。两人距离比普通同学更近，但画面表达克制，重点是依赖、保护、青春期的隐秘情绪。
```

### 3.3 成年关系：重逢 / 拉扯 / 和解

```text
成年陶淮南与成年迟骋同框。陶淮南气质温和清透，眼神空而安静，主动靠近但保持克制；迟骋高大冷淡，表情疏离，眼神压着情绪。两人之间有强烈旧情、分离后的克制、重逢的紧张和未说出口的疼痛。
```

## 8. 使用建议

1. 先生成单人母版：陶淮南童年、迟骋童年、陶淮南青年、迟骋青年。
2. 每张母版确认后，放入 `references/character_master/`。
3. 每次双人或章节图，都同时引用对应年龄段母版。
4. 童年阶段只表达陪伴、保护、依赖，不表达暧昧。
5. 青年阶段可表达重逢、拉扯、克制、和解，但避免低俗化。
