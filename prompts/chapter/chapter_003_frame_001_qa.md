# Prompt QA 验收清单

- 故事：第3章｜冰溜子：第一次示好
- 场景：农村老屋和窗外冰挂

## 必须通过
- [ ] 人物年龄、发型、服装、体型符合角色锁定
- [ ] 陶淮南盲人视觉表现明确
- [ ] 场景年代、季节、道具符合场景锁定
- [ ] 画风连续稳定
- [ ] 9:16竖屏，2-3格漫画分镜，主画面 + 特写小窗
- [ ] 画面不出现人物姓名标签、章节标题、帧序号
- [ ] 默认只出现空白气泡和空白旁白框，文字供后期叠加

## 人物检查
- [ ] 陶淮南：必须是8岁盲人小孩，不是普通能看见的小孩。
- [ ] 大而清亮但不聚焦的黑眼睛
- [ ] 视线不能准确对准人物、碗、冰溜子、门口或镜头
- [ ] 奶白肤色，脸颊柔软圆润，神情软、敏感、安静
- [ ] 根据声音转头，而不是用视线追踪
- [ ] 用手摸索炕沿、碗、冰溜子确认位置
- [ ] 迟苦：必须是瘦、苦、脏、沉默防备的农村小孩。
- [ ] 明显瘦，肩窄，衣服空荡
- [ ] 脸上冻红、旧伤痕、脏污，表现克制不血腥
- [ ] 破旧脏棉衣或朴素旧衣
- [ ] 少说话，动作收着
- [ ] 常低眼、偏头、后退或缩手
- [ ] 陶晓东：必须是年轻哥哥、家庭顶梁柱、纹身师气质但不是黑帮。
- [ ] 黑色半长发，长度到肩膀附近
- [ ] 默认随手扎成小马尾或小辫子，未扎时自然垂落
- [ ] 深色旧厚外套、旧军大衣、旧毛衣或朴素工装外套
- [ ] 常蹲下、弯腰或挡在孩子前面
- [ ] 动作稳，有保护感

## 场景检查
- [ ] 场景：农村老屋和窗外冰挂
- [ ] 空间：北方农村老屋，火炕、漏风窗、旧木门、院子和灵棚气氛
- [ ] 天气/季节：寒冬、厚雪、坚冰、窗框冰溜子、刺骨寒风
- [ ] 关键道具：火炕、饭碗、冰溜子、火盆、纸灰、军大衣、小毯子、瓜子
- [ ] 感官细节：柴火味、纸灰味、炕面发热、鼻尖冰冷、风砸窗声、冰挂掉落声

## 分镜检查
- [ ] 画幅必须为 9:16
- [ ] 必须是 2-3 格漫画分镜
- [ ] 布局必须包含 主画面 + 特写小窗
- [ ] 空间建立镜头
- [ ] 动作推进镜头
- [ ] 手部、道具或人物反应特写

## 文字检查
- [ ] allow_text_in_image 默认必须为 False
- [ ] 文字模式：生成空白气泡 + 后期叠字图层
- [ ] 人物姓名标注：不标注
- [ ] 不得出现人物姓名标签、章节标题、第几帧、顶部标题栏或中文乱码

## 返工规则
- 如任一项失败，保留人物母版图、场景母版图、首帧锚点图和上一帧成图，只修复失败项；反复失败时更新 config 或 docs 规则。
