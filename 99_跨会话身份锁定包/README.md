# 跨会话身份锁定包

这个目录是为了解决“当前会话能稳定，新会话就变脸/换猫”的问题。

## 为什么会变

只靠文字 Prompt，模型每次都会重新理解“年轻女生”“白色银渐层猫”，所以切换新会话后，人物和猫的长相会漂移。要跨会话稳定，必须把参考图当成身份锚点使用。

## 新会话必传图片

每次新开对话或换工具时，先上传：

1. `01_原始参考图_每次新会话必传/R01_human_identity_ref.jpg`
2. `01_原始参考图_每次新会话必传/R02_cat_identity_ref_front.jpg`
3. `01_原始参考图_每次新会话必传/R03_cat_identity_ref_close.jpg`

然后再上传可选母版图：

- 居家沙发绿植：`02_母版参考图_稳定风格可选/M01_sofa_green_front_4x3.png`
- 居家 45 度：`02_母版参考图_稳定风格可选/M02_sofa_green_45deg_4x3.png`
- 送外卖：`02_母版参考图_稳定风格可选/M03_delivery_front_4x3.png`

## 参考优先级

1. 原始人像图：锁定女生脸、眼镜、发型、气质。
2. 原始猫图：锁定猫的品种、圆脸、大眼、毛色。
3. 母版图：锁定你已经满意的构图、风格、衣服和场景。
4. Prompt：只负责本次动作、角度、服装、比例和氛围。

## 稳定出图口诀

新会话不要只发 Prompt。必须先发身份参考图，再发生成 Prompt。
