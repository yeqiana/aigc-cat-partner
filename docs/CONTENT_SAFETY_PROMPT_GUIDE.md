# 内容安全 Prompt 生成规范

本规范用于降低连续漫画出图 Prompt 被平台内容政策拦截的概率。它不是规避审核，而是把剧情里的危险、伤害、冲突和儿童处境改写成合规、克制、可视化的表达。

后续所有章节 Prompt、返工 Prompt、人物母版 Prompt、场景母版 Prompt 都必须先经过本规范检查，再进入出图工具。

## 总原则

1. 以保护、陪伴、情绪变化和生活质感为重点，不以伤害细节、羞辱、恐惧猎奇为重点。
2. 儿童角色只表现处境、表情、距离、依赖和被照顾，不表现裸露、性化、受虐细节或血腥伤口。
3. 暴力冲突只表现结果和阻止动作，不表现击打瞬间、喷血、开放伤口、虐打过程。
4. 酒后冲突、追赶、威胁等内容要改写成“危险临近”“被拦住”“站位对峙”“保护动作”，不写具体施暴细节。
5. 受伤只用克制生活化视觉：冻红、发抖、旧伤痕、衣服脏破、疲惫、躲闪、被大衣裹住。
6. 不写裸露儿童、洗澡裸体、身体隐私部位、性暗示、亲密暧昧姿势。
7. 不写“血喷出”“光身”“抽筋”“殴打”“虐待过程”等容易触发拒绝的直白词。
8. 不把人物写成黑帮、暴力反派、霸总压迫、犯罪审美。

## 高风险词改写

| 原始高风险写法 | 推荐改写 |
| --- | --- |
| 追打、殴打、打到流血 | 危险追赶、冲突闯入、被迫后退、保护者上前阻止 |
| 头上喷血、满脸血、血流一地 | 额角有旧伤痕、脸色苍白、衣领凌乱、被毛巾轻轻按住伤处 |
| 光身、脱光、裸露 | 穿着宽松旧衣、裹着毛巾或旧毯、避开身体隐私 |
| 抽筋、痉挛、濒死 | 身体发抖、蜷缩、虚弱、需要被扶住 |
| 虐待、暴打、家暴现场 | 家庭冲突后的余波、孩子躲闪、成年人阻拦、门口对峙 |
| 醉酒父亲挥棍打孩子 | 醉酒成年人闯入，保护者用长棍横在门口阻止靠近 |
| 伤口特写 | 手攥紧衣角、破旧袖口、毛巾、药瓶、担忧表情特写 |
| 恐怖、惊悚、猎奇 | 压抑、寒冷、紧张、克制、生活化 |
| 黑帮气场、凶狠压制 | 可靠保护者、疲惫但温热、强硬阻拦但不施暴 |

## 儿童角色安全边界

儿童角色包括陶淮南、迟苦及所有童年线人物。必须遵守：

- 必须穿完整衣物，或被毯子、外套、毛巾包裹。
- 不画身体隐私部位，不强调身体曲线，不使用成人化姿势。
- 洗澡、换衣、受伤检查等场景只表现门外等待、毛巾、药箱、衣物、照顾动作或人物表情。
- 可以表现害怕、沉默、防备、发抖、靠近安全人物，但不要表现虐打过程。
- 迟苦的苦和脏要通过旧棉衣、冻红、脏污、瘦弱和沉默表达，不能通过裸露伤痕或血腥表达。

## 暴力与伤害改写规则

当原文包含暴力、追打、流血、重伤时，Prompt 必须转成以下结构：

```text
危险来源：远景或门口出现，不做施暴动作特写。
保护动作：陶晓东站到孩子和危险之间，用身体、门框、长棍或大衣形成阻隔。
儿童反应：迟苦后退、缩肩、攥衣角；陶淮南听见声音后偏头，不准确看向危险。
视觉证据：凌乱衣角、雪地脚印、打翻的盆、药瓶、毛巾、担忧表情。
禁止：血腥伤口、击打瞬间、裸露儿童、虐待过程。
```

## 可直接复用的安全描述

### 危机闯入

```text
寒冬院门被推开，醉酒成年人停在门口形成压迫感；陶晓东站到两个孩子前方，用身体和门框挡住靠近路线。迟苦缩肩后退，陶淮南听见声响后偏头，手指摸住炕沿确认位置。画面只表现紧张站位和保护动作，不表现击打、血腥或虐待过程。
```

### 受伤后的照顾

```text
孩子穿着完整旧衣，被厚外套或旧毯包住，脸色苍白、发抖；桌上有药瓶、毛巾和热水盆，成年人蹲下照看。重点表现被保护、被安置和关系变化，不表现裸露身体、开放伤口或血腥细节。
```

### 洗澡或换衣相关场景

```text
只表现浴室外的毛巾、干净衣物、热水雾气和照顾者递衣服的手；儿童始终被毛巾、睡衣或毯子遮住，画面重点是生活照顾和安全感，不出现裸露、身体隐私或暧昧构图。
```

## Negative Prompt 必加项

```text
不要血腥、喷血、开放伤口、击打瞬间、虐打过程、裸露儿童、儿童身体隐私、性暗示、猎奇恐怖、犯罪审美、黑帮化、霸总压迫、施暴特写。
```

## Lint 前置检查

生成 Prompt 后，如果出现以下内容，必须重写：

- 儿童 + 裸露、脱光、光身、身体隐私；
- 血喷出、满脸血、血流、开放伤口、伤口特写；
- 殴打、暴打、虐待过程、施暴动作特写；
- 黑帮、犯罪、凶狠施暴、霸总压迫；
- 把伤害当成画面卖点；
- 把儿童恐惧、疼痛、身体细节写得过于直白。

## 后续维护规则

如果某类 Prompt 多次被平台提示“可能违反内容政策”，不要只改当次 Prompt，必须把触发原因沉淀到：

- `docs/CONTENT_SAFETY_PROMPT_GUIDE.md`
- `config/prompt_policy.json`
- `tools/prompt_linter.py`
- 对应章节输入或分镜配置

沉淀后再重新生成章节 Prompt。
