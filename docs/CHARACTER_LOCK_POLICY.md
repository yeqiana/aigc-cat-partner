# Character Lock Policy

本文件解决连续漫画生成中的人物形象固定问题。人物锁定优先级最高：当剧情动作、构图、文字排版与人物设定冲突时，必须保留人物设定。

## 陶淮南｜童年

必须是 8 岁盲人小孩。

强制视觉规则：
- 大而清亮但不聚焦的黑眼睛；
- 视线不能准确对准人物、碗、冰溜子、门口、镜头等目标；
- 经常根据声音转头，而不是用视线追踪；
- 用手摸索炕沿、碗、冰溜子、毯子、衣袖来确认位置；
- 身体动作谨慎，不独自快速奔跑；
- 神情软、敏感、安静，紧张时抓衣角、摸炕沿或靠近哥哥；
- 是被哥哥保护得很好的盲人小孩，不是普通能看见的小孩。

禁止：
- 正常对视；
- 准确盯着物体；
- 看向镜头互动；
- 画成普通能看见的小孩；
- 成年化、少年化、偶像化；
- 夸张白内障、恐怖失明效果；
- Q版幼儿化。

## 迟苦｜童年

必须是 8 岁左右、瘦、苦、脏、沉默防备的农村小孩。

强制视觉规则：
- 肩窄、明显瘦，衣服空荡；
- 脸上冻红、旧伤痕、脏污，表现克制不血腥；
- 破旧脏棉衣或被陶晓东换上的朴素旧衣；
- 表情防备、沉默、少说话；
- 站姿收着，常低眼、偏头、后退或把手缩在袖口里；
- 面对陶淮南时可以有很短暂、克制的软化，但不能开朗表演。

禁止：
- 干净漂亮小男孩；
- 现代城市儿童；
- 开朗阳光、富养精致；
- 成年化、少年化；
- 情绪夸张表演；
- 反派化、邪气化；
- 血腥伤口或裸露受虐画面。

## 陶晓东｜25岁

必须是 25 岁左右的年轻哥哥、家庭顶梁柱、纹身师气质但不是黑帮。

强制视觉规则：
- 黑色半长发，长度到肩膀附近；
- 默认随手扎成小马尾或小辫子，未扎时自然垂落、有生活感；
- 深色旧厚外套、旧军大衣、旧毛衣或朴素工装外套；
- 高大、肩宽、手掌大；
- 眼神疲惫但温热；
- 外糙内细、可靠护短，动作常是蹲下、挡在孩子前面、递衣服或扶孩子。

禁止：
- 短发；
- 寸头；
- 精致油头；
- 韩式男主；
- 黑帮；
- 暴力反派；
- 霸总；
- 潮牌网红；
- 满臂夸张纹身；
- 忽略对孩子的保护动作。

## 返工沉淀规则

如果出图中出现以下问题，不能只改当次 Prompt，必须检查并更新项目级约束：

- 陶淮南看起来能正常看见；
- 陶淮南眼睛对准人或物；
- 陶淮南年龄漂移；
- 迟苦变干净、漂亮、开朗或城市化；
- 陶晓东变短发、寸头、黑帮、霸总；
- 服装、发型、年龄线连续两次以上漂移；
- 角色被画成人物姓名标签或介绍浮标。
