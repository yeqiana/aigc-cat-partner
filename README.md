# AIGC 人猫搭档 Project V1.4

这是一个用于稳定生成“同一个女生 + 同一只白色银渐层猫”的 AIGC 图片项目包。

## V1.4 修复重点

本版本重点修复：**多张竖屏大图虽然能生成，但之前更像“同一个角色在不同场景的几张图”，不够像一个前后连贯的故事。**

V1.4 现在改为：

1. `continuous_story=是` 时，默认不再只做“多场景变体”，而是自动生成 **起-承-转-合** 的镜头序列。
2. 连续故事输出时，任务文件会明确告诉你：**必须按顺序生成，第 2 张开始要把前一张成图继续作为参考图上传。**
3. 新增故事模板：`外卖跑单故事`、`居家治愈故事`、`自动判断`。
4. 新增故事连续性强度：`story_coherence=强`，默认开启。
5. 扩展了故事场景：`楼下抬头`、`送达门口`、`收工回家`，让故事更完整。

## 最快使用方式

1. 解压项目包。
2. 打开 `99_跨会话身份锁定包/新会话_必须上传清单.md`。
3. 新会话里先上传 3 张原始参考图。
4. 打开 `入口/入口_开始这里.html`。
5. 选择：`比例=9:16`、`生成张数>=3`、`连续情节=是`。
6. 故事模板建议选：`外卖跑单故事` 或 `居家治愈故事`。
7. 复制生成的任务文件，**按顺序一张张生成，不要一次全并行。**
8. 第 2 张开始，把上一张成图继续作为参考图上传。

## 连续故事最推荐配置

```bash
python tools/generate_prompt.py --scene 送外卖正面 --ratio 9:16 --platform 抖音竖屏 --image-count 6 --continuous-story 是 --story-template 外卖跑单故事 --story-coherence 强 --bubble-mode 双气泡 --text-mode 空白气泡后期加字 --copywriting-mode 自动根据情节生成 --interaction-mode 评论引导
```

## 关键提醒

**连续故事稳定的关键，不是“生成 6 个 prompt”，而是：**

```text
第1张先出锚点
第2张用第1张继续生成
第3张用第1张+第2张继续生成
后续每一张至少带上“首张锚点 + 上一张成图”
```

否则很容易退化成：同一个角色在不同背景下摆拍，而不是一段故事。
