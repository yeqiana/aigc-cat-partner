# 从这里开始｜人猫搭档 V1.7

## 最简单用法

1. 打开 `入口_开始这里.html`。
2. 先在 `常用配置模板` 中选择一个模板。
   - 常用外卖故事：`外卖跑单·连续故事常用`
   - 常用居家故事：`居家治愈·连续故事常用`
   - 可以修改选项后点击 `保存为模板`
   - 可以点击 `新建模板` 创建自己的常用组合
3. 在 `故事情节` 中填写本次故事本身。
   - 例如：第一天送外卖，接到第一单，检查猫背带，到店取餐，路上配送，最后送达。
4. 在 `补充说明` 中填写额外约束。
   - 例如：不是散图、每张承接上一张、不要换服装和道具。
5. 如果要做抖音图文，选择：
   - 比例：`9:16`
   - 平台：`抖音竖屏`
   - 生成张数：例如 `5`
   - 连续情节：`是`
6. 如果要自动生成文案：
   - 文案生成：`自动根据情节生成`
   - 文字模式：推荐 `空白气泡后期加字`
   - 文字落地模式：推荐 `生成空白气泡 + 后期叠字图层`
7. 如果要锁定同组图服装：
   - 服装风格锁定：`强锁定`
   - 服装参考来源：`第一张锚点图 + 人物参考图`
8. 如果要互动：
   - 观众互动：选择 `提问互动` / `评论引导` / `选择投票`
9. 当前图内分镜默认保持 `关闭`；只有明确需要多视角表达时再开启。
10. 复制右侧 Prompt。
11. 新会话先上传 3 张身份参考图，再上传对应母版图，然后发 Prompt。

## 推荐默认组合

```text
模板：外卖跑单·连续故事常用
比例：9:16
生成张数：5
连续情节：是
气泡模式：双气泡
文字模式：空白气泡后期加字
文字落地模式：生成空白气泡 + 后期叠字图层
文案生成：自动根据情节生成
观众互动：评论引导
服装风格锁定：强锁定
当前图内分镜：关闭
```

## 故事情节和补充说明的区别

```text
故事情节：本次故事讲什么，按什么顺序发生。
补充说明：额外限制、禁忌项、返工要求。
```

不要再把完整故事只写进 `补充说明`。这样后续脚本才能把故事规划、分镜和文案拆得更清楚。
