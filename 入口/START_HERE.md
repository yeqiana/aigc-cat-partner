# 从这里开始｜人猫搭档 V1.3

## 最简单用法

1. 打开 `入口_开始这里.html`。
2. 选择场景。
3. 如果要做抖音图文，选择：
   - 比例：`9:16`
   - 平台：`抖音竖屏`
   - 生成张数：例如 `5`
   - 连续情节：`是`
4. 如果要自动生成文案：
   - 文案生成：`自动根据情节生成`
   - 文字模式：推荐 `空白气泡后期加字`
5. 如果要互动：
   - 观众互动：选择 `提问互动` / `评论引导` / `选择投票`
6. 复制右侧 Prompt。
7. 新会话先上传 3 张身份参考图，再上传对应母版图，然后发 Prompt。

## 推荐默认组合

```text
比例：9:16
生成张数：5
连续情节：是
气泡模式：双气泡
文字模式：空白气泡后期加字
文案生成：自动根据情节生成
观众互动：评论引导
```
