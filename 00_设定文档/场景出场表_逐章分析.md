# 《陈年烈狗》场景出场表 — 逐章分析

> 小说作者：不问三九  
> 主线：陶淮南（盲人）× 迟骋（迟苦）  
> 叙事跨度：陶淮南 8 岁 → 25 岁  
> 核心主题：成长、陪伴、分离、重逢

---

## 主要角色一览

| 角色 | 关系 | 关键词 |
|------|------|--------|
| 陶淮南 | 主角（盲人） | 奶膻味、怕黑、耳朵灵敏、话多黏人、表面高冷实际嗲精 |
| 迟骋（迟苦→迟骋） | 主角，陶淮南的小哥 | 烈狗、脾气大、沉默寡言、从小被打、护短、心软 |
| 陶晓东 | 陶淮南的亲哥，纹身师 | 温柔坚毅、会赚钱、宠弟、后与汤医生在一起 |
| 汤索言 | 陶晓东的伴侣，眼科医生 | 温和靠谱、气场强大、医援 |
| 十爷爷 | 陶淮南的金毛犬 | 陪伴→离世（第16章） |
| 田毅 | 晓东的好友 | 热心帮忙 |
| 黄哥（大黄） | 晓东的合作伙伴 | 迟骋法律上的监护人 |
| 石凯 | 高中同学→好友 | 沉稳、后与潘小卓在一起 |
| 季楠（楠哥） | 高中同学，富二代 | 话多闹腾、中二热心 |
| 潘小卓（小卓） | 陶淮南高中同桌兼好友 | 内向学霸、后与石凯在一起 |
| 凡果（果儿） | 迟骋的学弟 | 话痨活泼、被陶淮南"收买" |
| 江极 | 盲人乐队成员 | 声音像迟骋、脾气暴躁 |
| 齐医生 | 心理医生 | 陶淮南的导师和咨询师 |

## 第一部：相识与收养（第1-5章）

### 第1章 初遇

| 项目 | 内容 |
|------|------|
| **场景** | 陶晓东老家（北方农村），灵棚前 |
| **季节** | 寒冬腊月 |
| **出场角色** | 陶淮南（8岁，盲人）、陶晓东（25岁）、迟苦（约8岁，光着身子的男孩）、老家叔叔、老太太（迟苦奶奶） |
| **核心事件** | 父母骨灰落葬期间，陶淮南在灵棚前被迟苦抢了牛奶。迟苦光着身子冻得发抖，是他爸迟志德酒后打的。迟苦跑走。 |
| **关键画面** | ①寒冬腊月光着身子的迟苦抢牛奶喝 ②陶淮南被吓到缩进哥哥怀里 ③陶晓东用大衣裹住迟苦 |
| **备注** | 迟志德是陶晓东同村人，醉酒的酒鬼，常打孩子 |

### 第2章 收留

| 项目 | 内容 |
|------|------|
| **场景** | 陶家老屋、火炕 |
| **季节** | 寒冬 |
| **出场角色** | 陶淮南、陶晓东、迟苦、老太太、迟志德 |
| **核心事件** | 迟苦深夜逃到陶家院子躲打。陶晓东赶走迟志德，把冻僵的迟苦带回炕上。两个小孩第一夜共处一室。迟苦用饭盆帮陶淮南接尿。 |
| **关键画面** | ①迟苦蹲在熄灭的火盆边发抖 ②陶晓东把光着的迟苦夹回屋 ③迟苦缩在炕沿边打颤 ④两个小孩偷偷用饭盆接尿 |
| **关联记忆** | 迟苦后来改名为迟骋（第37章） |

### 第3章 冰溜子

| 项目 | 内容 |
|------|------|
| **场景** | 陶家老屋 |
| **出场角色** | 陶淮南、陶晓东、迟苦 |
| **核心事件** | 陶淮南因把迟苦饭碗用来接尿而心虚，把自己的饭分给他。迟苦为陶淮南摘冰溜子（冰挂）摸。陶淮南问"你爸为什么打你""你咋不跑"，迟苦被问跑。 |
| **关键画面** | ①陶淮南拍炕沿让迟苦吃他的饭 ②迟苦摘了长长一根冰溜子扔炕上 ③陶淮南摸冰溜子觉得新奇（这是他第一次"见"冰） |
| **备注** | "冰溜子"是对迟苦老家口音的体现 |

### 第4章 领走

| 项目 | 内容 |
|------|------|
| **场景** | 老家→乡道→县医院→陶晓东家 |
| **出场角色** | 陶淮南、陶晓东、迟苦、迟苦奶奶、迟志德 |
| **核心事件** | 陶晓东回头取陶淮南的小毯子，撞见迟苦被迟志德一镐头打抽了，满头血。陶晓东垫付医药费。奶奶下跪求陶晓东把孩子带走。一周后迟苦出院，被带回城里的家。 |
| **关键画面** | ①迟苦光着抽搐被奶奶端出来 ②奶奶下跪求陶晓东带走孩子 ③车上陶淮南给迟苦棒棒糖："以后你在我家没人打你了" |
| **备注** | 迟苦正式进入陶家，改口叫陶晓东"哥" |

### 第5章 新家

| 项目 | 内容 |
|------|------|
| **场景** | 陶晓东家（两室两厅） |
| **出场角色** | 陶淮南、陶晓东、迟苦 |
| **核心事件** | 迟苦原名"迟苦"（奶奶起名，贱名好养活）。陶晓东给两人一起洗澡，迟苦一身伤。陶淮南的狗"十爷爷"不在身边。两人分房睡，迟苦贴墙睡三十公分，陶淮南翻滚一占一米二。 |
| **关键画面** | ①陶淮南说"你名儿真不好听，叫迟甜多好" ②陶晓东给迟苦搓澡搓下很多泥 ③半夜陶淮南掉地上，迟苦跳下来帮他 |
| **备注** | 迟苦"小时候长得丑"，陶淮南"奶白奶白的" |

## 第二部：上学与磨合（第6-16章）

### 第6章 上学准备

| 项目 | 内容 |
|------|------|
| **场景** | 陶家 |
| **季节** | 冬→春 |
| **出场角色** | 陶淮南、陶晓东、迟苦、保姆阿姨 |
| **核心事件** | 陶晓东为俩小孩办盲校入学，让迟苦陪读一年照应陶淮南。陶淮南因迟苦不理人而失望。两个孩子处于别扭状态。 |
| **关键画面** | ①陶淮南一条腿搭在迟苦肚子上睡觉 ②陶晓东与迟苦谈话，让他照顾弟弟 ③陶淮南搂着十爷爷说舍不得 |
| **备注** | 陶晓东坦白有私心：让迟苦陪读照顾陶淮南 |

### 第7章 入学

| 项目 | 内容 |
|------|------|
| **场景** | 盲校教室、宿舍 |
| **出场角色** | 陶淮南、迟苦、老师、奶奶（宿管） |
| **核心事件** | 陶淮南入学第一天大哭，抓住迟苦不肯松手。迟苦陪读明眼小孩，在盲校格格不入。晚上两人隔着栏杆牵手睡。 |
| **关键画面** | ①一群小瞎子哭了一天 ②陶淮南紧紧抓着迟苦不松手 ③迟苦从栏杆间伸手让陶淮南攥着 |
| **备注** | 往后五年（直到转校），两人在学校一直牵手 |

### 第8章 回家

| 项目 | 内容 |
|------|------|
| **场景** | 盲校→陶家→田毅家 |
| **出场角色** | 陶淮南、迟苦、陶晓东、田毅、田婶 |
| **核心事件** | 周五一接回家，俩小孩又谁也不理谁。田毅开玩笑说要把迟苦送走，陶淮南急了说"我俩可好呢"。 |
| **关键画面** | ①陶晓东把陶淮南放脖子上骑着出校门 ②陶淮南在田毅家说"我俩可好呢" ③迟苦躲着不亲近人 |
| **备注** | 俩小孩"在学校手牵手，回家互不搭理"的模式持续好几年 |

### 第9章 校内模式

| 项目 | 内容 |
|------|------|
| **场景** | 盲校、陶家 |
| **出场角色** | 陶淮南、迟苦、陶晓东、十爷爷 |
| **核心事件** | 周一返校，陶淮南找不到迟苦就慌。两人在学校形成"牵着不分开，出校门就互不理"的诡异模式。 |
| **关键画面** | ①陶淮南摸到迟苦才安心 ②陶晓东看监控发现俩小孩在学校根本不分开 ③回家后俩人在不同地方吃冰 |
| **备注** | 陶晓东："塑料朋友" |

### 第10章 体育课与敏感期

| 项目 | 内容 |
|------|------|
| **场景** | 盲校操场、教室、宿舍 |
| **出场角色** | 陶淮南、迟苦、体育老师、奶奶 |
| **核心事件** | 陶淮南盲道走不好被体育老师批评，觉得自己是最笨的。迟苦嫌他烦。陶淮南失落一整天，第二天又主动找迟苦和好。 |
| **关键画面** | ①陶淮南扔了盲杖搂住迟苦 ②迟苦说他"就你事儿多" ③陶淮南早上摸空迟苦的床，急得要哭 |
| **备注** | 陶淮南依赖迟苦，迟苦不爱表达 |

### 第11章 工作室与眼睛

| 项目 | 内容 |
|------|------|
| **场景** | 陶晓东纹身工作室、盲校 |
| **出场角色** | 陶淮南、迟苦、陶晓东 |
| **核心事件** | 暑假去工作室。迟苦陪着陶淮南。深夜回家陶晓东抱一个牵一个。迟苦开始纠正陶淮南乱转眼睛的毛病。 |
| **关键画面** | ①深夜小区，陶晓东一手抱陶淮南，一手牵迟苦 ②"谢谢小弟了，让哥省不少心" ③迟苦按着陶淮南眼睛不让乱动 |
| **备注** | 迟苦第一次被叫"小弟" |

### 第12章 眼睛矫正

| 项目 | 内容 |
|------|------|
| **场景** | 盲校、陶家 |
| **出场角色** | 陶淮南、迟苦、陶晓东、英语老师 |
| **核心事件** | 迟苦持续纠正陶淮南转眼睛的习惯。陶淮南委屈说"我不跟你好了"。陶晓东也说"眼睛乱动像小傻子"。英语老师丢粉笔头批评陶淮南。 |
| **关键画面** | ①迟苦捏着陶淮南眼珠不让他动 ②陶淮南疼哭了说"我不跟你好了" ③粉笔头从陶淮南肩膀弹到迟苦桌上 |
| **备注** | 眼珠乱动的问题花了几个月才改好 |

### 第13章 保护与成长

| 项目 | 内容 |
|------|------|
| **场景** | 盲校、放学路上、车里 |
| **出场角色** | 陶淮南、迟苦、陶晓东、三年级熊孩子 |
| **核心事件** | 三年级学生推陶淮南，迟苦反手把人推了个跟头。陶晓东教他们"走到平地了再推，推完赶紧跑"。陶淮南和迟苦的小别扭翻了篇。 |
| **关键画面** | ①迟苦楼梯上推人 ②陶晓东护短："谁欺负你们就欺负回去" ③迟苦第一次笑开了 |
| **备注** | 迟苦的处事方式："打还手骂还口" |

### 第14章 寒假出游与迟苦生病

| 项目 | 内容 |
|------|------|
| **场景** | 长途自驾→酒店→医院 |
| **出场角色** | 陶淮南、迟苦、陶晓东、大黄 |
| **核心事件** | 寒假跟着哥出门。迟苦起疹子发烧，半夜去医院。陶淮南吓得哭。迟苦不让陶淮南靠近怕传染。 |
| **关键画面** | ①迟苦躺陶晓东怀里去医院 ②陶淮南坐床上抹眼泪等 ③迟苦让陶淮南枕自己腿睡觉 |
| **备注** | 迟苦第一次被人抱着去医院看病 |

### 第15章 十爷爷离世

| 项目 | 内容 |
|------|------|
| **场景** | 陶家 |
| **出场角色** | 陶淮南、陶晓东、迟苦、田毅、十爷爷（金毛） |
| **核心事件** | 十爷爷太老要走了。陶淮南崩溃大哭。迟苦说"以后我是你的狗"。 |

| **关联记忆** | "小狗"的约定从本章开始，贯穿全书 |

### 第16章 小狗约定

| 项目 | 内容 |
|------|------|
| **场景** | 陶家 |
| **出场角色** | 陶淮南、陶晓东、迟苦 |
| **核心事件** | 陶淮南从"小狗"的安慰中走出来，两人形成默契约定。过年时陶晓东问要不要新宠物，陶淮南说"我有迟苦啦"。 |
| **关键画面** | ①陶淮南指着迟苦房间说"我有迟苦啦" ②"人前是小哥，人后是小狗" ③两个穿红衣的小孩 |
| **备注** | 从此"小狗"成了两人私密的代号 |

## 第三部：转学与青春期（第17-35章）

### 第17章 不离校

| 项目 | 内容 |
|------|------|
| **场景** | 陶家 |
| **出场角色** | 陶淮南、迟苦 |
| **核心事件** | 迟苦原本该转出盲校，但他拒绝了，留下来继续陪陶淮南。陶淮南开心坏了，软乎乎地"汪汪"。 |
| **关键画面** | ①陶淮南嘴长泡上火 ②迟苦说"我说要走了？" ③陶淮南搂着迟苦汪汪叫 |
| **备注** | 迟苦在盲校多陪了两年 |

### 第18章 成长与初中小升初

| 项目 | 内容 |
|------|------|
| **场景** | 陶家、公园 |
| **出场角色** | 陶淮南、迟苦、陶晓东 |
| **核心事件** | 两人一起转普通校，迟苦跳级。迟苦管陶淮南学习很严。跑步时陶淮南赌气停下，迟苦发大火。 |
| **关键画面** | ①陶淮南枕着迟午睡，腿搭在迟苦身上 ②迟苦给陶淮南补课 ③陶淮南站斜坡上赌气，迟苦发火 |
| **备注** | 迟苦在普通校考了第三 |

### 第19章 狗绳

| 项目 | 内容 |
|------|------|
| **场景** | 陶家、小公园 |
| **出场角色** | 陶淮南、迟苦、陶晓东 |
| **核心事件** | 陶淮南整了根狗绳拴自己手腕上要跑步用。迟苦气得摘下来扔了。迟苦消气后继续带陶淮南跑步。 |
| **关键画面** | ①陶淮南套着狗绳美滋滋："我不本来就是你的小狗吗" ②迟苦气得说不出话 ③迟苦说"遛狗的东西拿来遛瞎子？" |
| **备注** | 迟苦拒绝用狗绳遛人 |

### 第20章 初中开学

| 项目 | 内容 |
|------|------|
| **场景** | 初中教室 |
| **出场角色** | 陶淮南、迟苦、雷老师、同学们 |
| **核心事件** | 迟苦自我介绍"陶淮南是我弟"，被笑名字"吃苦"。陶淮南不习惯新环境。迟苦教他"除了牵手不能有其他动作"，定了"三级标准"。 |
| **关键画面** | ①教室里所有人都看陶淮南 ②迟苦自我介绍引起笑声 ③陶淮南给迟苦定"三级行为标准" |

### 第21章 护短

| **出场角色** | 陶淮南、迟苦、后面俩男生 |
| **核心事件** | 后桌说迟苦"学习好的都是呆子"，陶淮南反击"呆子也比傻子强"。陶淮南气了一整天。 |

| **备注** | 陶淮南护短，迟苦人缘慢慢变好 |

### 第22章 提升课

| 项目 | 内容 |
|------|------|
| **场景** | 初中教室、医院 |
| **出场角色** | 陶淮南、迟苦、陶晓东、学习委员（舒敬）、汤医生（首次出现） |
| **核心事件** | 迟苦被选入提升班，每天最后两节课不在。陶淮南要独自等迟苦。汤医生首次出现（声音好听）。学委和迟苦一起上课。 |
| **关键画面** | ①陶淮南趴桌上等迟苦 ②迟苦跑上来接他 ③迟苦作业给学委，自己没写挨说 |
| **备注** | 汤医生是陶晓东未来的伴侣，此处首次出场 |

### 第23章 早恋误会

| 项目 | 内容 |
|------|------|
| **场景** | 初中教室、陶家 |
| **出场角色** | 陶淮南、迟苦、前桌女生、学委 |

| **备注** | 这是陶淮南第一次对"恋爱"有感知 |

### 第24章 厕所欺负

| 项目 | 内容 |

3. **冰溜子**——童年第一次互动的记忆
4. **枕巾**——盲校时两人隔着栏杆牵手的工具
5. **心跳**——陶淮南的安全感来源，迟骋的心跳声
6. **手环**——迟骋为陶淮南定制的导航，承载11年牵手的默契
